## Delivery policy

Keep reviewable increments; one task per session by default. Build genuine capabilities progressively. Unknowns are resolved by experiments, not guessed defaults. Dependencies in TASKS.md are the execution graph. Split tasks where necessary without losing acceptance criteria.

## Scope pressure

Defer convenience features first (supported defeaturing breadth, Word output or advanced viewing) with an explicit exception record. Never silently cut bonded assemblies, trustworthy numerics, core result inspection, privacy or spending protection.
