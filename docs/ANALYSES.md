# Independent analyses and shared geometry

Open a project and use **Open analysis** to select its saved setup. Each analysis keeps its own geometry revision, material assignments/provenance, display units, supports/loads/directions, mesh controls and run history. Importing newer geometry does not repin an earlier analysis. **Refresh analyses (keep selected setup)** discovers copies created in another browser tab without changing your current setup or drafts.

Expand **Duplicate saved setup**, enter a new analysis name and click **Duplicate analysis setup**. Empty source revision means the current saved revision; enter an earlier saved revision to branch from that historical setup. Apply/Save or Cancel existing drafts first. The copy shares the exact original immutable geometry and starts at revision 1 with independent settings. Runs, exports and job histories stay with the original. A conflicting source head refuses; reload the saved workspace before duplicating again. If the response is lost, refresh the analysis list and inspect it before retrying.

The **Checked mesh** selector offers verified compatible completed meshes from this project, including other analyses. Options identify source name/revision; the panel shows source analysis, compatibility SHA-256 and exact mesh artifact SHA-256. Use **Refresh compatible meshes** after another tab finishes a mesh. Material/load/name/display-unit edits may reuse connectivity; changes to geometry revision, physical global/local sizing, curvature or the pinned tool/source policy require a new mesh. Even identical BREP bytes in a different revision do not imply compatibility. Unsaved mesh sizing blocks solving. Preview the selected immutable mesh, review the current setup and explicitly submit a solve; the server repeats all checks.

A new run freezes the target analysis and actual selected mesh/deck. Editing either analysis later cannot alter it. Select the original analysis and its completed solve to reopen historical results; frozen revision, raw source hashes, original material/yield data and geometry remain visible. The copy inherits no results and cannot present the source's result as its own. The same behavior survives actual API restart.

The local supported path remains bounded C3D10/affine-planar independent bodies with the existing native, quality, equilibrium and resource guards. General bonded setup begins at T019; mesh reuse is not mesh convergence or design approval.
