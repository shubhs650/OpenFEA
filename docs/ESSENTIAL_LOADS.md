# Global component supports, body gravity and equilibrium

Open a geometry-pinned analysis and confirm its materials. In **Supports, face loads and body gravity**, existing fixed faces, signed planar pressure and total distributed force retain their SI/source semantics. No point loads, remote moments, arbitrary local directions or implicit stabilization are added.

Choose **Prescribed global displacement component**, select complete CAD faces, choose X/Y/Z and enter a displacement in the current length unit. Zero is allowed and acts as a component support. Only that component is constrained; other translations remain free. Create separate assignments for additional components. Shared edges/vertices inherit face constraints. Equal values on one node/DOF deduplicate; contradictory values refuse without overwriting either value. Fully fixed faces still constrain all translations. The server checks necessary rigid-motion coverage on CAD and actual mesh; sufficient support coverage is not a general stiffness/assembly validity certificate. Distributed CLOAD forces cannot act on a constrained component; pressure/body loads retain their checked distributed-load contract.

Choose **Gravity (body acceleration)** and explicitly select complete bodies. Enter the global X/Y/Z acceleration in the displayed acceleration unit, for example `[0, 0, -9806.65] mm/s²` or `[0, 0, -9.80665] m/s²`. Density is canonical kg/m³: `7.85e-9 tonne/mm³` means `7850 kg/m³`. Only gravity-loaded bodies require density. Missing density leaves weight unavailable, withholds the whole assignment's resultant and blocks export/solve. Meshing may still precede complete material/load setup. A known preview uses native CAD volume/centre of mass to report rho×V×g and its moment about the global origin. Legacy geometry without the native centre requires reimport before gravity. Gravity annotations lead from the native body centre to a visible arrow outside the body; blue component arrows indicate prescribed/support directions, not forces. Arrow lengths are illustrative.

Overlapping physical face loads or body accelerations require explicit combination permission. Signed vectors add; saved source values/units remain available even when loads intentionally cancel. Global component supports are distinct from load combination. Oversized/poor meshes and unsupported curved solving remain blocked by the [mesh contract](MESH_CONTROLS.md).

Saving appends an immutable analysis revision. Unit/material/name edits carry physical/source assignments forward; unsaved numeric drafts clear on display-unit changes. Queued/running inputs never change. Geometry cleanup carries only verified unchanged full face assignments. Gravity always needs body/weight review after cleanup because mass/centroid can change: explicitly reselect current bodies or remove the assignment. Acceleration/source values survive review. Undo restores captured source controls in a fresh revision, while old runs retain their own geometry, materials, loads and outputs.

Generate/review a compatible mesh and solve the complete supported affine C3D10 setup. The downloadable deck contains explicit component boundaries, density and native GRAV; no equivalent CLOAD body force is added again. Quadratic body integration retains negative corner and positive midside weights. Native exit zero and output coverage alone do not establish equilibrium. Run validation subtracts the written applied CLOAD, pressure and consistent gravity from DAT RF and counts only constrained global components. Nonzero imposed components contribute actuator reactions; free-node/internal-tie forces do not become external supports. A failed balance publishes no valid result and retains diagnostic native outputs without retry.

Completed **Force and moment equilibrium** results show residual vectors/norms, reference magnitudes, allowed residual, method and pass state in the selected display units. Moments use global origin `[0, 0, 0]`. Force reference sums frozen physical load magnitudes plus nonzero prescribed-component actuator forces; it is not net applied force. Moment reference includes the load moment magnitudes and at least force reference × the frozen model's largest extent. Declared development limits are 0.5% relative with separate `1e-6 N` / `1e-6 N·m` absolute floors. Near-zero reference uses the absolute check and shows normalized residual unavailable. Self-equilibrated pressure therefore retains a meaningful nonzero reference, while genuinely tiny loads show no invented percentage. Display units, contour clipping or deformation exaggeration never change these measurements. A pass is not mesh convergence, model certification or design approval.

[ADR-023](adr/ADR-023.md), [API contract](API_CONTRACT.md) and [T015 evidence](validation/T015.md) retain exact criteria, source/tool hashes and native/browser/restart results. B03–B05 are development evidence with pending owner review; B03's original coarse stress failure and explicitly refined mesh revision are retained without widening tolerances. To run a declared diagnostic, use `make benchmark CASE=B03 DEVELOPMENT=1` (also B04/B05), or the CLI's `--output` with a fresh ignored directory for a separate retained run. Unsigned non-development execution refuses before creating output. Arbitrary directions/symmetry are T016; general assemblies/convergence and target-laptop/owner acceptance remain later gates.
