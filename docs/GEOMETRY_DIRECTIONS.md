# Geometry directions and planar symmetry

In a geometry-pinned analysis, choose **Total force along geometry direction**, or **Prescribed displacement component** and its **Direction source**. Existing global XYZ force/components and global body gravity remain available. Select complete CAD faces as physical targets; the direction reference can be another face or edge in the same pinned geometry. Edges are direction sources only, never point/edge load targets.

Choose a planar outward normal, straight edge or cylindrical axis, select its native reference and inspect **Direction and sign**. Straight-edge positive direction follows its native ordered endpoints. Cylindrical-axis positive direction follows the native axis, rather than a guessed radial normal. **Reverse selected direction** negates the selected axis. The server resolves the immutable source, signed unit vector, origin and right-handed orthonormal X′/Y′/Z′ basis; it does not accept a user-authored basis. The table shows all axes in global coordinates. Purple arrows illustrate the draft direction and fit outside the opaque part; arrow length is illustrative and changes no physical load origin or magnitude. Numeric drafts clear on display-unit changes, while saved SI/source values remain exact.

Enter a signed scalar force in the current force unit; it becomes one total global vector uniformly distributed over the entire selected face set once. A negative scalar reverses force relative to the selected X′ direction. Overlapping applied loads still require explicit combination. For displacement, enter a length in the current unit (zero allowed). Only its selected component is constrained by that assignment; other translations remain free unless other supports also constrain them. Saved directions retain source kind/reference, sign, vector, complete basis and geometry revision alongside original quantity/unit provenance.

Choose **Planar symmetry (normal displacement zero)** and select complete planar faces. Each face uses its own native outward normal; multiple planes can be selected together. Symmetry constrains normal translation and leaves tangential components free. Curved symmetry is refused before saving. Native CAD vertex incidence and actual mesh nodes identify shared supports. Equal or reversed-equivalent constraints deduplicate; contradictory values, inconsistent dependent combinations or a nearly singular constraint basis refuse. No transform overwrites, constraint removal, force redistribution or stabilization occur.

Legacy imports without native straight-edge/cylinder-axis data require reimport for those sources. New imports retain body-owned edge/vertex identities and line endpoints, with at most 20,000 edges and vertices each. Face picking/LOD/mesh preview never changes the pinned direction identity. Cylinder axes can be selected, previewed and saved on real cylindrical CAD; curved meshes remain inspection-only and curved solving/export remains unavailable. The current solve path is independently supported, affine C3D10/planar geometry under the existing 100-face/3,000-element limits.

Geometry cleanup conservatively invalidates every geometry-derived direction, even if its target face maps as unchanged. Saved original scalar/SI quantities and old source/basis remain available; stale arrows/resultants are withheld and compute is blocked. First explicitly reselect target faces. Symmetry reselection recomputes each native planar normal. Other directional assignments then require **Reselect direction for …** using a current native reference. The original scalar is preserved while the explicitly reviewed direction can change. Undo restores captured original source references against restored geometry in a fresh revision; it refuses to overwrite later edits. Completed runs keep their original geometry/setup/deck/results through review, units and restart.

Review/save supported mesh controls, generate a compatible mesh, then solve. The downloadable deck combines all supports into one compatible rectangular frame per constrained node, with local boundaries and converted local CLOAD. Pressure and gravity keep their native/global semantics. Global DAT/FRD output is explicitly required for transformed nodes. Reaction processing subtracts written applied loads and projects global RF onto the external constrained span; internal/free components do not become supports. Nonzero imposed components contribute actuator references. T015's frozen relative/absolute equilibrium policy, prescribed-output check and fail-closed publication remain unchanged. Mesh convergence, general stiffness/assembly certification and design safety are separate gates.
