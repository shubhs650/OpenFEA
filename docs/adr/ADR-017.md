# ADR-017: Canonical materials and immutable analysis display preferences

Status: Accepted for T009 development
Date: 2026-10-13 (Asia/Calcutta)

## Decision

Use a single server-owned preset catalog for mm–N–MPa, m–N–Pa and inch–lbf–psi. Derive stress/density from force, length and seconds; keep all physical values canonical SI. Store display preference separately from material quantities. A unit-only transaction copies existing canonical and source properties verbatim; a form keeps SI separately from display text so switching units does not repeatedly round-trip physics.

Add Alembic revision `0003_analysis_materials` with one immutable material setup row per analysis revision, referencing existing revision keys. Read legacy revisions without setup rows as explicitly empty default-unit drafts. Assign/remove and unit edits acquire the existing immediate write transaction, validate ownership/tombstone/expected analysis revision, resolve body IDs in the pinned geometry, append both revision/setup, and advance the head atomically. Name edits copy the preceding setup. New geometry never automatically repins an analysis or transfers materials.

Copy sample/custom properties, source values/units, library identity/version, source references, grade/condition, temperature notes, assumptions and confirmation into each assignment. Library GET returns templates without user confirmation; sample application includes the reviewed version and refuses a changed library. Opening saved examples uses the frozen copy. Custom URL references are HTTP(S) metadata, not server fetch targets. There is no editable global library or run snapshot claim here; T011 must freeze this setup into the actual run.

Retain the existing development material guard 0 ≤ ν ≤ 0.45 and warn at ν ≥0.4. E must be finite/positive; supplied density/yield must be finite/positive before and after conversion. Unknown/unvalidated ratios, invalid fields and conversion overflow refuse, without clamping or tolerance widening. Missing density/yield produce explicit gravity/yield-factor prerequisite blockers on saved bodies; actual gravity loads/results remain later work.

## Evidence and limits

[T009 evidence](../validation/T009.md) records independent dimensional conversion references, zero drift through unit-only revisions, immutable source copies after library edits, competing writes, legacy migration/reversal, real API-process restart, native axial material responses and browser workflows. Fixed native criteria are 1e-11 m displacement and 10 Pa raw stress-tensor error; endpoint/interior Poisson checks are limited axial compatibility evidence, not a full material validation envelope or owner-accepted benchmark.

[Operator guide](../MATERIALS_UNITS.md) documents unusual but dimensionally consistent density units, Apply/Cancel and conflict/reload behavior. Samples cite primary manufacturer data while their assumed Poisson ratios are visible. No dependency, native binary/lock, existing benchmark criterion or signed acceptance changed. The [M0 owner exception](../validation/M0-owner-decision.md), target-laptop gate, complete engineering workflow and later run/results obligations remain open.
