# ADR-026 — Independent saved analyses and exact mesh reuse

Status: ACCEPTED for bounded T018 local development
Date: 2026-10-14

## Decision

POST `/analyses/{id}/duplicates` accepts an explicit saved `source_revision` and new `name`, protected by CSRF and current source If-Match. Copy the stored geometry reference, display units, complete immutable material snapshots/provenance, complete load/support/direction/review state and mesh setup into revision 1 of a new analysis in the same owned live project. Do not mutate the source or copy runs, jobs, exports or artifacts. This uses existing append-only tables and needs no migration. T017 conflict copying uses the same transactional helper but retains its strictly superseded-revision requirement. Historical duplication preserves that revision's geometry, never the project's latest import.

The real workspace exposes current/historical saved setup duplication and analysis list refresh without changing the active setup. Drafts must be applied/cancelled first. New copies have independent names, setup revisions and job/result histories; existing analysis selection restores its own pinned geometry. Existing revision conflict and bounded session undo semantics remain in force. A lost duplicate response is unacknowledged; refresh the list before manually retrying. No automatic metadata retry is introduced.

Permit explicit mesh reuse across analyses only within the same owned live project and exact geometry revision. Compute a canonical SHA-256 over schema version, complete immutable geometry metadata (including UUID, BREP/artifact hashes and topology catalog), physical SI global/local sizes, curvature and the entire existing tool/source/quality/isolation policy. Sort local controls by physical target. Exclude analysis identity/name/revision, display units, materials, loads and recovery permission: they do not alter accepted connectivity. Empty/default versus explicit size stays conservatively distinct. Equality is exact, without tolerance widening or nearest-geometry matching. Recovery algorithm profiles remain part of the frozen policy.

GET `/analyses/{id}/compatible-meshes` offers at most the latest 100 completed project mesh jobs after exact compatibility comparison and original snapshot/mesh byte verification. Responses identify the current analysis revision, source analysis/revision/name and both compatibility and mesh artifact hashes. No failed/pending job, mismatched geometry/size/policy or unverifiable artifact is offered. Refresh when a mesh completes, the analysis revision changes or the user explicitly requests other-tab updates; guard asynchronous responses by analysis/revision. The browser removes stale choices and requires renewed review; sizing drafts block solve.

Solve admission independently repeats project/geometry/current-head, physical settings, full policy, compatibility hash and snapshot/mesh integrity checks. It rebuilds the deterministic deck from the target's frozen material/load inputs and selected immutable connectivity. A new run pins the source mesh job, exact mesh artifact SHA-256 and compatibility SHA-256. The new optional mesh-source hash field preserves reading earlier snapshots without rewriting their bytes. Existing quality, face mapping, supported affine/planar physics, equilibrium, queue/idempotency/isolation and resource checks remain mandatory. Old runs remain bound to their original analysis, input/deck/native/parsed hashes and physical settings.

## Verification and limits

[T018 evidence](../validation/T018.md) records complete-copy/edit independence, historical geometry, ownership/CSRF/tombstone/stale heads, concurrent tabs, actual variant solves sharing exact connectivity, stale geometry/size/local/curvature/policy and corrupted-source refusal, real process restart and M2 regression. There are no persisted bond assignments before T019; this does not implement or certify general assembly bonding. Bounded candidate/list windows are explicit; no cross-project mesh cache, automatic remeshing or convergence claim is introduced. Owner-signed benchmarks, Windows/Edge/headed GPU and target-laptop acceptance retain existing deferrals.
