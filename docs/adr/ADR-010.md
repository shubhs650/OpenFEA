# ADR-010: Pinned separate native environments and CPU source build

Status: Accepted for T002 development availability
Date: 2026-10-12

## Decision

Build CCX 2.23 from official sources with serial SPOOLES 2.2 and its official CCX correction; link open-source ARPACK-NG 3.9.1 and Netlib BLAS/LAPACK 3.12.1. Use GNU 14.2.0, 32-bit solver integers and single-thread job settings. Keep OCP/OCCT, Gmsh/OCCT and VTK in three separately locked Python 3.12 environments. Pin official source and signature-authenticated Debian package hashes; install everything in ignored workspace paths.

OCP 8.0.1.1.0 bundles OCCT 8.0.1 and requires VTK 9.6.2. Gmsh 4.15.2 bundles OCCT 7.8.1. Postprocessing uses VTK 9.7.1. Their real operations passed in separate interpreters. This accepts availability, not geometry mapping or result semantics.

## Evidence and bounded fallback

[T002 evidence](../validation/T002.md) records one real C3D10 solve, nine native tests, exact artifacts/licenses and repeatable setup. `unshare` is unavailable here, so the native fallback uses no-new-privileges/seccomp socket denial, closed inherited descriptors, minimal environment and resource limits. Denial is exercised, not inferred from stripped proxy settings. This is not yet a complete filesystem/hostile-upload sandbox.

GCC 14 exposed legacy source conventions. The build uses `-fcommon`, a narrow return-mismatch warning downgrade and Fortran argument-mismatch compatibility; no numerical source changes or tolerance relaxation. The relocatable compiler needs its exact gcc/libgcc development packages. The installer applies only documented/official SPOOLES corrections to extracted copies and rejects changed artifact digests.

## Consequences

Native checks are now required in complete setup. Hash-verified builds are retained, while jobs/probes restart in future tasks. No proprietary linear algebra backend, Docker requirement, fake solve, worker service or solver UI is introduced. Public license remains deferred; source offers, notices, wheel bundles and OCCT/Gmsh exceptions require review before redistribution. T003/T004/T005 remain responsible for mapping, stress locations and ties; M0 is not closed.
