# ADR-005: Scientific result provenance

Status: Proposed
Date: 2026-10-12

## Decision
Native volume processing plus vtk.js display; preserve raw/derived field location metadata.

## Rationale
Section cuts and unaveraged stress require more than colored exterior triangles.

## Evidence/gate
F5 and numerical interpolation/probe tests; explicit body boundaries.

## Alternatives not selected
Displaying averaged FRD fields as unaveraged values

## Consequences
Maintain the boundary in implementation and tests. If evidence contradicts this choice, add a superseding ADR with affected tasks; do not overwrite historical rationale. No executed validation is asserted by this record.
