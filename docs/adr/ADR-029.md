# ADR-029: Full frozen result fields and partitioned tensor smoothing

Status: Accepted for bounded development; engineering-owner benchmark acceptance pending
Date: 2026-10-14 (Asia/Calcutta)

T021 extends the existing owned immutable result derivative, not the solver/raw result format. The versioned view exposes native displacement magnitude and signed global ux/uy/uz; all six canonical stresses xx,yy,zz,xy,yz,zx; von Mises; and algebraically ordered principal stresses s1≥s2≥s3. Field metadata identifies SI units, global frame and raw node/IP extrema with entity IDs, coordinates and body/material side. Native IP tensors remain authoritative; native FRD averaged stress stays diagnostic only.

Unaveraged element-node contours remain the default. Use the existing affine C3D10 four-point tensor extrapolation, including all quadratic midsides, before deriving scalar invariants. Optional smoothing is the equal-weight arithmetic mean of incident element-node tensors at an identical mesh node, separately keyed by body and material. Every incident volume element contributes once, including interior elements; duplicated surface faces add no weight. Never merge nodes by coordinates or cross a body/material boundary. Keep element-owned boundary vertices even when their partition shares a smoothed value. Compute von Mises and principal stresses **after** tensor averaging, never by averaging invariants. Record contribution counts and the complete method. Smoothing can hide jumps and is not convergence evidence.

Both modes are deterministic read-only derivatives from the same frozen verified input/mesh/deck/DAT/FRD/parsed result. Existing raw artifact bytes, job records, reactions/equilibrium, raw extrema and frozen yield factors stay unchanged by display choices. Current processor version/source hashes identify the derivative; no run is silently rewritten and historical material values never come from the current analysis. Existing ownership/deletion/integrity and bounded affine input gates remain mandatory.

The UI exposes every field with location/frame/method information. Length and stress presets convert only at display boundaries; signed component/principal contours allow negative limits. Displacement magnitude/von Mises retain nonnegative limits. Mode/field changes reset contour clipping; unit changes retain applied SI limits. Warnings and the raw extrema/yield/equilibrium tables remain visible across changes. Smoothing never modifies native displacement or deformation. A smoothed peak is not a new safety or yield-factor result.

Independent hydrostatic, compressive, pure-shear and rotated-tensor references, opposite-sign tensor means, body/material/shared-node partitions, actual B09 native discontinuity, actual axial/two-body/bracket API results, restart and browser tests validate the path. [Predeclared derivative criteria](../../tests/fixtures/native/result-fields.json) retain 1e-10 relative tensor derivation and existing axial criteria; no benchmark tolerances, native caps, dependencies, solver binaries or retries change. Probes/sections remain T022, refinement T023, M3 engineering gate T024 and owner/laptop/formal benchmark acceptance remain pending.
