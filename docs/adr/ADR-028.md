# ADR-028: Necessary assembly preflight and bounded zero-gap mortar solve admission

Status: Accepted for bounded development; engineering-owner/formulation acceptance pending
Date: 2026-10-14 (Asia/Calcutta)

## Decision and scope

T020 connects the reviewed T019 setup to actual generated decks and durable local mesh/solve jobs. Graph edges come only from immutable, explicitly approved, geometry-pinned face pairs. Validate the complete frozen report SHA-256, roles, measurements, policy and current catalog before using an edge; repeat native overlap/pair measurements at compute admission. Proximity alone creates no connection. Stale, missing/same-body, reused-face, duplicate/cyclic and unsupported multiple solver connections refuse rather than silently dropping rows.

Necessary support checks operate on each disconnected component, using actual support directions and normalized rigid-motion rows `u=t+ω×x`. A rank below six identifies missing support coverage, including detached loaded bodies. CAD/display preflight is guidance; actual mesh-node checks run again in deck generation, read-only mesh preflight and worker validation. Connected components combine support rows only across reviewed full interfaces. **Passing these checks is not proof of stiffness rank or stability.** No weak springs, hidden boundary conditions, solver substitution or automatic retry is added.

The product solve path is deliberately one **complete axis-aligned planar zero-gap unit-square interface**, two independent body meshes and at most 65 nodes per interface trace, using ADR-013's consistent mortar equations. Existing C3D10 quality, mapping, load audits, raw DAT/FRD validation, fixed equilibrium and native resource gates remain mandatory. No node merge/fuse, geometry movement or failed native `*TIE` fallback. Actual quadratic memberships and full projection/area/affine/traction-transfer checks precede emission. Slave SPC/MPC conflicts and transformed-node bonded constraints refuse. Loads exceeding the existing 1e-10 N fixed/dependent-DOF threshold on slave nodes refuse; no external forces are moved to make the model solve. Unsupported finer traces request an explicit modeling/mesh decision; never silently coarsen or omit nodes.

A mesh with an assembly-specific constraint conflict remains a useful mesh preview, with a solve blocker and no generated deck. Solve/export independently repeat the checks. The read-only preflight appends no analysis, job or artifact and checks owner/CSRF/current head and exact immutable mesh/tool/sizing compatibility. Ordinary independent-body and single-body behavior remains supported.

## Physical-gap boundary

T019/B08's approved **review** of a physical gap is retained, including its explicit tolerance/assumptions and immutable history. It does not grant product solve permission. B08 validates only axial displacement continuity across a 10 µm void, without adhesive compliance/contact. For a general rigid rotation, points separated by `g` have different displacements `ω×g`; simply equating all translations across the void does not preserve that rigid mode. Therefore general physical-gap rotation/shear/bending cannot be inferred from an axial patch. Product physical-gap solves remain refused until a separately validated formulation/model decision. The B08 experiment and its frozen criteria are unchanged, not relabeled as product/general assembly acceptance.

## Native publication gates

Only internally generated deterministic `*EQUATION` rows are emitted. Retain every nonzero coefficient. Validate native results against the actual 12-decimal exponent coefficients written in the frozen deck, not unprinted full-precision intermediates. Native free-equation count must equal `3*nodes - unique_SPC_DOFs - 3*slave_nodes`; every intended slave translation is accounted for. All-node continuity residual must meet the existing 2e-11 m B07 criterion. Unexpected bonded solver warnings fail. Persist `assembly.json` with source mesh/review identity, component support counts, coupling/coverage/equation audit, written coefficients and the necessary-only warning alongside the frozen deck/raw outputs.

Recognized singular, pivot, indefinite or rigid-mode native messages fail with actionable `solver_singular` diagnosis. The actual B11 diagnostic may still print “Job finished” and finite huge displacements for unsupported bodies without such a message. Neither a finish marker nor finite vectors override preflight, exact constraints or frozen external force/moment checks. No displacement-magnitude threshold is invented as a substitute for stability analysis. Failed jobs retain bounded diagnostics and never publish `results.json` or calculated result views.

Run snapshots retain reviewed setup; restart, edits and old raw results remain independent. General multiple bonds, transformed bonded constraints, curved/nonunit/partial/physical-gap interfaces, scalability, convergence and owner/laptop/Windows acceptance remain unvalidated.
