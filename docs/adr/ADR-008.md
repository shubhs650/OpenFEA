# ADR-008: India beta and data separation

Status: Accepted design baseline
Date: 2026-10-12

## Decision
India application data/processing; synthetic-only Codex fixtures; no external CAD telemetry.

## Rationale
Development cloud locality does not establish production data residency.

## Evidence/gate
Infrastructure region tests, artifact routes and diagnostic redaction.

## Alternatives not selected
Using private customer models in cloud coding sessions

## Consequences
Maintain the boundary in implementation and tests. If evidence contradicts this choice, add a superseding ADR with affected tasks; do not overwrite historical rationale. No executed validation is asserted by this record.
