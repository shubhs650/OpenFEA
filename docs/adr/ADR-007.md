# ADR-007: Cost admission and failure credits

Status: Accepted design baseline
Date: 2026-10-12

## Decision
Server reservations, independent deadlines/TTL, append-only usage and credits; mesh/solve approval only.

## Rationale
Provider alerts lag; credits still cost the operator real money.

## Evidence/gate
Race, runaway, interruption and cap tests plus dated AWS budget worksheet.

## Alternatives not selected
Browser timers or AWS alerts as sole cap

## Consequences
Maintain the boundary in implementation and tests. If evidence contradicts this choice, add a superseding ADR with affected tasks; do not overwrite historical rationale. No executed validation is asserted by this record.
