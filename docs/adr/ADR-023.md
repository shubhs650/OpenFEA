# ADR-023 — Global component supports, body gravity and external equilibrium

Status: Accepted for bounded development implementation; engineering-owner benchmark acceptance pending
Date: 2026-10-14 (Asia/Calcutta)

T015 extends immutable load setups with one prescribed global X/Y/Z displacement component on complete selected CAD faces (zero is allowed; other components remain free), and global acceleration on selected complete bodies. Convert displacement/acceleration to SI once and retain original source values/units. Density is required only on gravity-loaded bodies; missing density leaves weight unavailable and blocks export/solve. Explicit combination permission is required for overlapping applied face loads or overlapping body accelerations. Same-value supports deduplicate; different values on one global DOF refuse, including shared face edges/vertices. Do not overwrite, stabilize, remove or redistribute constraints/loads. Force CLOAD on any constrained component retains the existing >1e-10-N refusal.

New native OCCT imports retain body volume centres of mass for gravity previews. Legacy geometry without that field requires reimport before gravity. Changed-body gravity references always need explicit body reselection/removal because mass/centroid changes even if acceleration does not. Face component supports follow the existing conservative whole-face mapping rules. Undo restores captured source controls; old runs and raw bytes remain immutable.

Retain the affine/planar C3D10 solve contract, fixed numerical/load-audit/native/resource guards and no solver retry. Necessary independent-body rigid-motion coverage is six-dimensional: normalize positions by the body's extent and rank the translation/rotation constraint rows with a declared dimensionless 1e-10 threshold. Check both CAD display and actual mesh supports; this is a necessary local support test, not the later general assembly/stiffness certification. Fully constrained models with no free equations remain refused.

Pinned CCX 2.23 manual sections *BOUNDARY, *DENSITY, *DLOAD and *NODE PRINT define global component boundaries, positive mass density, GRAV magnitude/unit-direction and RF as external reaction plus applied concentrated/distributed loads. Emit density for gravity-used material sets and deterministic axis-decomposed GRAV entries to preserve written acceleration without rounding a normalized arbitrary vector. Sum explicitly approved accelerations per body; never duplicate equivalent CLOAD body loads. Check actual decimal-written physics against original SI/CAD resultants under unchanged 1e-8-N/1e-8-N·m deck criteria.

For affine C3D10 constant body loading, the exact consistent weights are -V/20 at each corner and V/5 at each midside (sum V); do not use equal node shares or discard negative corner weights. Recover the written generated deck's CLOAD, pressure and consistent gravity, subtract them from DAT RF and retain only explicitly constrained global components. Count each external node/DOF once. Nonzero prescribed components contribute actuator reactions. Internal ties/MPC/free-node RF never become external supports. Preserve per-body reactions and global force/moment totals about the documented global origin.

Predeclare development equilibrium checks: relative residual <=0.005; separate absolute floors 1e-6 N and 1e-6 N·m. Force reference is the sum of magnitudes of frozen physical applied load contributions plus magnitudes of nonzero prescribed-component actuator reactions, rather than net force. Moment reference is at least force reference times the frozen model's largest extent, and includes summed applied moment magnitudes about the origin. Use absolute comparison when reference*0.005 <= its absolute floor; report normalized residual as null there. Never divide by a near-zero net load or show fabricated percentages. An imbalance fails run validation, retains diagnostic native outputs and publishes no valid engineering result. Successful views retain both residual vectors, norms, references, criteria, limits and pass states; a pass is not a convergence/design-safety certificate.

Before execution, B03–B05 manifests freeze two mesh sizes, mathematical references, sampling/exclusions and exact tolerances. B03 is a 1×0.1×0.1-m solid cantilever, nu=0, Euler–Bernoulli tip mean within 2%, central bending stress within 5% at predeclared non-root/non-neutral samples (finite-width/shear caveats explicit). B04 is a unit cube with zero global normal components on the three coordinate-zero faces and inward pressure on opposite faces; all-node hydrostatic contraction/all-IP stress and reactions have an exact continuum reference. B05 is a nu=0 unit cube fixed at z=0 with uniform gravity; exact quadratic displacement/linear stress and rho*V*g references cover all nodes/IPs and corrected support reactions. New manifests remain PENDING owner review; DEVELOPMENT=1 cannot become formal acceptance. Existing frozen manifests/criteria and M0 owner/laptop deferrals remain unchanged.

The real UI/API must save/review inputs, display gravity/component glyphs and unknown-weight blockers, preserve settings through unit/material edits/restarts and cleanup/undo, execute actual native solves and expose frozen equilibrium in results. Required tests include units/density/body targeting, conflicting/duplicate/partial constraints, self-equilibrated and near-zero loads, prescribed actuator reactions, pressure/gravity on supports, internal-force exclusion, output/ownership integrity and real Chromium workflows. Arbitrary directions/symmetry are T016; general assembly preflight is T020; curved solving, convergence and laptop/owner acceptance remain later gates. No deployment/billing/private CAD expansion.

Initial development finding, before executing revised B03 meshes: revision 1's 0.08-m mesh met tip displacement but failed the unchanged 5% interior stress criterion (worst 8.05157312256193%). A quadratic tetra displacement interpolant does not exactly represent the cubic beam displacement/bilinear bending stress. Retain the original manifest and failure; revision 2 explicitly refines to 0.04/0.035 m. Reference, physical setup, sample/exclusion regions and every numerical tolerance remain identical; no product sizing changes automatically. Both revised meshes must pass before T015 completion. Owner review remains pending.

Executed [T015 evidence](../validation/T015.md) retains both revised B03 passes, exact B04/B05 references, real component/gravity/actuator/equilibrium publication, persistence and browser checks. The original B03 failure remains retained. Benchmark sign-offs stay PENDING; M0 owner and target-laptop deferrals are unchanged.
