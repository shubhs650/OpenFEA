# ADR-032 — Immutable shared report model and offline A4 PDF

Status: Accepted for the bounded local T025 slice
Date: 2026-10-15

## Decision

Consume one owned, succeeded solve through the existing hash-verified historical result path. Recheck retained DAT/FRD/mesh/deck/snapshot/results before rendering and at publication; recheck an optional comparison's second run independently. Never use current analysis materials, loads or geometry for an old run. A report appends an immutable model, HTML and PDF under a new UUID; SQL guards prohibit update/delete. Access joins the original job/project and respects tombstones. Already generated reports remain downloadable when original numerical files disappear; new reports refuse. Expiry scheduling and archive import remain T027/T036.

The versioned shared model contains frozen inputs, original run/mesh summaries, source/result hashes, source commit plus dirty flag and exact generator/processor/lock/font/binary hashes, complete warnings/assumptions, generic unit-labelled tables, trusted SVG figures, selected view definitions and an attributed user conclusion. T026 can consume these same facts. The original legacy solve does not record a complete hardware inventory; the PDF states that limitation rather than inventing CPU/RAM/thread measurements. Generator runtime identity is labelled separately.

Use existing locked Playwright/Chromium for print-to-PDF and the standard library's HTML escaping for the small fixed template; no Jinja dependency is needed. This refines the architecture's proposed HTML/Jinja adapter without adding a templating engine. No browser image/HTML/image URL is accepted. Server SVG projects actual verified boundary or authoritative volume-section samples using the saved model-centred camera. Far-to-near triangles use a disclosed flat vertex-scalar mean for colour only. This is a vector report derivative, not a pixel-identical vtk.js screenshot or a new stress invariant. Numerical tables remain the full all-body native extrema. Deformation, visibility, signed ranges and body/material tensor smoothing are explicit; camera and SI settings are in the downloadable model. Setup arrows are schematic direction markers on undeformed geometry, with complete physical assignment/target tables. Empty sections, missing bodies and invalid/behind-camera projections refuse.

One process-wide filesystem lock admits a report at a time. The renderer runs in Bubblewrap private user/PID/network namespaces with dropped capabilities, a minimal environment, readonly Node/Playwright/Chromium/system-library/font mounts and private scratch. No project storage, credentials or general network is mounted. Browser requests abort, JavaScript is disabled and CSP denies external resources. A sampled watchdog limits the tree to 45 seconds, 1 GiB RSS and 64 MiB scratch, kills the process group on every exit, cleans scratch and never retries. These are bounded development limits, not a target-laptop capacity measurement. Requests retain the existing 64 KiB metadata cap, at most four views, 40,000 triangles per figure and 16 MiB model/HTML/PDF limits. Failed rendering or source loss publishes no record.

A4 uses light backgrounds, embedded inline vector legends, readable fonts, repeating headers and bounded continuation rows for long source/provenance text. All original warning sets remain included regardless of selected views. Optional physical comparison includes both source identities, original warnings/assumptions, common-point changes, near-zero-relative semantics and separate moving raw peaks. No automatic safe-design/convergence finding is produced. User text is escaped and attributed separately.

## Verification and limits

`make test-reports` exercises real import/mesh/CCX/Chromium, historical setup edits, optional two-mesh comparison, actual sections, owner/CSRF/tombstone/expiry/corruption/failure/publication checks and database reopen. Poppler text, A4 word bounds and repeated-header checks accompany inspected rendered pages. The actual dark workspace exports a light report and rediscovers it after reload. See [T025 evidence](../validation/T025.md).

The existing package/uv/native locks remain unchanged. Chromium/Playwright are already provisioned; DejaVu Sans is a required system font and Poppler is a verification dependency. This adds no final redistribution approval. DOCX, archive import/export, comprehensive capacity/fault calibration and Windows/laptop/engineering acceptance remain their explicit later obligations. No deployment or merge is authorized by this ADR.
