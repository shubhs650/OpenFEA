# ADR-003: C3D10 and nonconforming ties

Status: Proposed
Date: 2026-10-12

## Decision
C3D10 meshes per body and validated CCX tied interfaces.

## Rationale
Matches chosen solids/assemblies scope without hiding bonds by fusing geometry.

## Evidence/gate
F3/F4 establish permutations, coverage, gap and adjustment behavior.

## Alternatives not selected
Automatic contact, node merging as a universal bond substitute

## Consequences
Maintain the boundary in implementation and tests. If evidence contradicts this choice, add a superseding ADR with affected tasks; do not overwrite historical rationale. No executed validation is asserted by this record.
