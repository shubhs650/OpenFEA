# ADR-019: Durable local mesh and solve jobs

Status: Accepted for T011 development
Date: 2026-10-13 UTC

## Decision

Add SQLite `local_jobs`, append-only `local_job_inputs` and `local_job_events` (migration `0005_local_jobs`). Admit a mesh job against the analysis ETag, or a solve against the analysis ETag and a completed owned mesh from that analysis/geometry/tool contract. Store one canonical immutable input in private content-addressed storage, including pinned geometry/material/load setup, source units/provenance, display, warnings, fixed limits and tool/runtime/source hashes. Mesh jobs use the T010 validated coarse planar adapter. Solve admission checks the chosen mesh and regenerates the actual deterministic deck against current materials/loads; the frozen run then pins that exact mesh and deck hash. There is no remeshing after solve admission, arbitrary input execution, rate estimate or hosted billing in this local slice.

Require a UUID `Idempotency-Key`. A same-owner key with identical analysis/revision/mesh request returns the original logical job, including after later analysis edits; changed payload conflicts. Recheck ownership/tombstone/current revision and duplicate key inside the immediate admission transaction. Cap active+pending work at 20; lists return the newest 100 records. Stored job identity/inputs/events and terminal rows cannot be mutated or deleted. Every stage heartbeat/completion is guarded by the claimed attempt token. A unique active-job index and atomic FIFO claim prevent duplicate execution.

Use one embedded worker thread per control process with an OS worker lock and the shared native import/export execution lock. Native children receive the same execution flock through Bubblewrap `--sync-fd`, retaining the lease through sandbox shutdown even if the control process dies. Browser requests only admit/read/cancel; browser closure never owns the worker lifecycle. Ordinary editing remains available during queued/running jobs and cannot change frozen inputs.

Pending jobs survive API restart. Graceful shutdown terminates in-flight native work and records interruption; abrupt restart acquires both OS locks, fences recorded process instances using boot-ID/start-time rather than recycled PID alone, retains bounded partial diagnostics, then marks the old attempt interrupted and resumes pending jobs. Interrupted attempts are not automatically retried. A control/fencing error blocks the worker instead of clearing an unknown lease or launching another solver. A fresh user submission is a new bounded job; later infrastructure retry/remote-worker protocols remain future work.

Queued cancellation is immediate because no native process has started. Active cancellation stays `cancelling` until the supervisor has terminated/waited for the native process group and the sandbox has exited; only then publish `cancelled`. Tombstoning a project requests cancellation in the same transaction, hides reads immediately and prevents successful finalization. Ownership change, cancellation, terminal state and stale attempt are checked again when publishing. Cancellation wins over completion if its request commits first. A browser timer/closed connection/heartbeat timeout never establishes process death.

Run only server-generated allowlisted input files with readonly mounts, private writable scratch, user/PID/network/filesystem namespaces, dropped capabilities, no fork/namespace escape/mount/ptrace and the verified netdeny launcher. No network or unconfined fallback. Retain the existing limits: 100 planar faces, 3,000 affine C3D10 elements; 60 seconds, sampled process-tree RSS 1,536 MiB and scratch 192 MiB per native stage, 1 GiB prelaunch disk reserve and existing hard CPU/address-space/file limits. The logical job has a 180-second bound. Native output reads refuse non-regular/symlink/oversized files. Trusted resource metadata uses exclusive no-follow creation so a native-created symlink cannot redirect a host write.

Success requires actual native completion and a complete verified artifact manifest. CCX exit zero alone is insufficient: require its finish marker, actual free equations, no recognized errors/singularity/pivot/convergence failure, and the existing strict single-static-step DAT/FRD adapters. Check finite values, complete node/IP coverage, actual frozen coordinates/topology/material ownership, frame and tensor order. Emit global `S,COORD` output using the already validated pinned keywords. DAT integration-point tensors remain authoritative; native FRD averaged node values remain separately labelled diagnostics. Keep raw input, DAT, FRD and logs, resource record, canonical parsed output and frozen warnings with hashes. Missing output/resource artifacts fail cleanly without publishing a result or blocking the next queued job. Failed/cancelled/interrupted raw files are diagnostic only.

The UI polls actual stage/heartbeat/time without a fabricated progress percentage. It previews actual quadratic boundary connectivity by subdividing each tri6 into four triangles, preserving midsides and catalog picking IDs. Solve review selects a completed immutable mesh and current revision; history identifies the run's original revision and geometry. Downloads stay linked to the old snapshot through later edits and restart. Calculated contours, deformation, extrema, equilibrium presentation and FoS remain T012/T015; raw-output validation is not convergence, general stability or design approval.

## Evidence and limits

[T011 evidence](../validation/T011.md) retains native axial/multi-material references, actual process cancellation, actual CCX/error/output-corruption cases, queue races, security probes, API death/restart and browser-close workflows. No dependency/native lock, compiled binary, frozen benchmark criterion or owner disposition changes. Curved/nonaffine meshes, local sizing/recovery, general assembly validation, hosted execution/billing, complete retention/purge and target laptop/engineering-owner acceptance remain later gates.
