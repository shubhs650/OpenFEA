# ADR-002: Versioned geometry and immutable runs

Status: Accepted design baseline
Date: 2026-10-12

## Decision
Immutable geometry revisions and run snapshots; explicit face references and ambiguous-remap invalidation.

## Rationale
Silent reassignment is worse than asking an engineer to reselect a face.

## Evidence/gate
Test selection reordering, cleanup, import/export and old-result provenance.

## Alternatives not selected
Transient CAD indices or mutable run inputs

## Consequences
Maintain the boundary in implementation and tests. If evidence contradicts this choice, add a superseding ADR with affected tasks; do not overwrite historical rationale. No executed validation is asserted by this record.
