# ADR-030: Owned physical probes and authoritative affine volume sections

Status: Accepted for bounded development; engineering-owner acceptance pending
Date: 2026-10-15 (Asia/Calcutta)

T022 adds read-only, owner-scoped POST probes and sections for completed local solves. Every request verifies the frozen input, mesh, deck, native DAT/FRD and parsed output through the existing result-integrity path, then rechecks ownership/deletion before returning. The response carries original run/source identities and current processor source hashes. No native solve, job state mutation or raw history rewrite occurs. Missing retained data refuses inspection; a prior surface or section cannot substitute. Automatic retention scheduling remains T036.

Probes require an explicit element ID and physical undeformed position in metres. Invert the affine tetrahedron map to barycentric coordinates and refuse points outside that side, allowing only 1e-12 reference-coordinate arithmetic roundoff. Never locate a boundary by silently choosing or averaging adjacent elements. Return the selected element/body/material, physical position, barycentric coordinates, `element_interpolated` location and interpolation method. Interior samples have no native node or integration-point identity.

Displacement uses all ten C3D10 quadratic shape functions in the tested CCX connectivity order. Unaveraged stress linearly interpolates the six tensors extrapolated from the element's four native integration points. Optional smoothed stress quadratically interpolates the complete ten-node tensor field, partitioned by exact body/material/node as in ADR-029. Calculate principal stresses and von Mises after interpolation. These are derived values, never raw node/IP measurements or new safety-factor extrema.

A section intersects the requested physical plane with each retained affine tetrahedral volume, orders the resulting three/four-sided polygon, and samples its corners, edge midsides and interior centroid. Render a fan of linear display triangles around that centroid. This bounds output to nine points/eight triangles per element: at most 27,000 points/24,000 triangles under the unchanged 3,000-element admission. Geometry/displacement and smoothed contours between samples are display approximations; the sampled values come from the full volume field. Tangency at a point/edge or a plane outside the volume yields an empty section. Coplanar adjacent element/body/material faces retain both sides; visibility controls choose bodies without averaging or coordinate merging. Normalize nonzero normals independently of magnitude and retain the normalized plane in the response. No surface clipping, exterior projection or fake interior coloring is authoritative.

The existing affine/planar solve boundary remains enforced, including the unchanged 1e-9 m midside and full-domain Jacobian guards. Curved CAD-projected mesh previews do not authorize curved results. Both probe and section tests must explicitly reject a moved curved midside, rather than silently treating it as a linear tetrahedron. Supporting curved volume intersections requires a separately validated isoparametric geometry implementation.

The actual workspace accepts unit-aware physical coordinates and explicit probe element IDs, with a retained-volume download for IDs. All fields and both tensor modes work on probes and sections. Automatic section contour ranges use the actual sampled section; native extrema, frozen yield, equilibrium and warnings remain independent. Reference coordinates remain undeformed even when rendering is exaggerated. Camera position/focal point/up/projection/scale/angle persist across field/mode/section/unit/theme/visibility updates within the open run; reset fits the geometry. View state is session memory, not a stored engineering artifact or report view. Changing/closing the run invalidates pending requests; missing/corrupt/expired data clears the displayed result. No cross-run derivative reuse or numerical cache is introduced in this bounded local slice.

[Predeclared inspection criteria](../../tests/fixtures/native/result-inspection.json) retain the existing tensor/axial criteria and declare independent polynomial/area arithmetic checks before numerical validation. Required checks cover analytic linear tensors, quadratic displacement, interior/face/edge/vertex probes, both boundary sides, known triangular/quadrilateral/coplanar/empty cut areas, scaled normals, curved refusal, actual native axial/varying shear, ownership/CSRF/deletion/missing sources, restart and real browser camera/stale-response/unavailable-data behavior. T023 refinement, T024 M3 exit, formal benchmark and target-laptop acceptance remain pending. No solver/dependency/native cap/retry or existing test deadline changes.
