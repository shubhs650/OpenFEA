# ADR-031: Frozen-physics refinement comparisons and retained assumption explanations

Status: Accepted for bounded development; engineering-owner acceptance pending
Date: 2026-10-15 (Asia/Calcutta)

T023 compares two completed owned runs from one project, at one to eight explicitly named undeformed physical positions. Each position supplies a body identity and an explicit element side in **each** mesh. Reuse T022's verified affine C3D10 interpolation, preparing each volume once for the bounded batch. Return reconstructed positions, barycentric coordinates, both tensor modes, quadratic displacement, source identities and the selected scalar change. Never compare unrelated node/IP numbers, project a point to the exterior, average across body/material sides or silently choose a boundary side. Curved/non-midpoint volume geometry remains refused under the existing guards.

Compute a versioned physical signature from the **frozen** geometry, per-body material properties/provenance, canonical loads/supports/directions/review state, reviewed bonds and numerical solver policy/sources. Geometry revision/project/body identity must match exactly; even an equivalent new import is a different model. Exclude analysis names/revisions/IDs, load IDs/names, display/source-unit representations and mesh sizing/recovery from the physical definition. Material provenance changes are conservatively incompatible. Preserve solver binaries, native libraries and numerical contracts; changes require separate comparisons rather than a false refinement claim. Different geometry/material/loading/support/bond/solver contracts return 409 with the differing categories, after checking both owners. Live setup edits cannot rewrite old comparisons.

Both runs must pass the existing frozen input/mesh/deck/native DAT/FRD/parsed-result integrity path. Recheck both owner/tombstone records after sampling. Missing or expired retained data refuses new comparison, including after an earlier successful read. No numerical cache, native solve, job mutation, automatic retry or raw history rewrite is introduced.

For selected scalar `q`, report signed change `compared-reference`, absolute change and `absolute_change/abs(reference)`. At or below the disclosed canonical reference floors (1e-12 m or 1e-6 Pa), relative change is null; absolute change stays visible. These are **display denominator conventions**, not acceptance tolerances. Reject nonfinite derived arithmetic. Signed stresses/components remain signed. Components use the canonical six-component/global frame; principal/von Mises invariants follow tensor interpolation, including the disclosed partitioned-smoothed mode.

Separate the raw native maximum **absolute-magnitude** sample (including its sign, physical position and node/IP identity) from common-location interpolation. A rising mesh-dependent peak gets a caution about unresolved concentrations/singularities; it is not proof of mathematical divergence. A lower peak, more elements, small sample change or one arbitrary comparison cannot prove convergence, stability, accuracy or safety. Identical meshes and non-increasing element counts get explicit notices. The response's `convergence_claim` is literally false, not a computed success badge. Smoothed samples never substitute for raw peak/yield assessment.

The current-source `affine-c3d10-assumptions-v5` result derivative adds structured explanations without modifying original frozen warnings/raw outputs. Per-body yielding uses raw IP von Mises and frozen supplied yield; missing/essentially-zero stress cannot invent a finite factor/assessment. Per-body maximum native displacement / largest extent retains the existing 1% screening threshold; passing it cannot bound local rotations/strain or certify small-deformation validity. A general singularity explanation has an **unassessed** state, not a claim that an automatic detector found a singularity. Existing yield-exceedance and displacement warnings remain. Field/unit/contour/deformation choices cannot suppress these explanations.

The workspace uses actual completed-run discovery (including explicit refresh), a session list of canonical physical locations/side bindings, the current field/mode and a unit-aware comparison table. Changing runs clears element-side bindings; changing fields invalidates the prior derivative while retaining physical points. Downloaded comparison JSON retains both frozen source identities, original warnings, all structured explanations, exact physical sample requests and interpolation/denominator conventions. This is a real engineering-data export; PDF/Word/report/archive features remain T025–T027. Locations persist in the downloaded JSON, not a new mutable run record. Browser reload persistence/import of comparison drafts is outside this bounded slice.

[Predeclared criteria](../../tests/fixtures/native/result-comparison.json) retain existing axial/tensor/interpolation tolerances and declare arithmetic/near-zero display conventions. Required evidence covers independent signed/near-zero deltas and divergent peak versus stable sample logic; physical signature changes/allowed presentation edits; actual two-mesh native axial fields, deliberately overstretched/yield-exceeding linear outputs, original bytes, owner/CSRF/stale/deleted/unavailable data, actual restart and real browser discovery/table/JSON download/warning retention. No synthetic or mocked solve is credited as numerical validation.

The aggregate hosted job limit increases from 20 to 25 minutes: the preceding T022 hosted check used **19m17s**, before the added multi-run native/browser workflows. This is administrative headroom for the complete setup/suites/failure probes; all individual test deadlines, native wall/CPU/memory/scratch limits, concurrency, retries, numerical criteria, binaries and dependency locks remain unchanged. T024 M3 exit, signed benchmarks and Windows/Edge/target-laptop/headed-GPU/performance/usability acceptance remain pending. No deployment or merge.
