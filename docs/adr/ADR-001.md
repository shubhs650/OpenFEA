# ADR-001: Native engineering workers

Status: Proposed
Date: 2026-10-12

## Decision
Run CAD, meshing, CCX and authoritative postprocessing as bounded native Linux processes behind typed adapters.

## Rationale
Browser-only WASM would enlarge porting/validation scope; a native pipeline supports local WSL2 and AWS reuse.

## Evidence/gate
F1–F5 must pass; no Docker daemon assumption in Codex Cloud.

## Alternatives not selected
Browser solver, FreeCAD GUI automation and custom FEM solver

## Consequences
Maintain the boundary in implementation and tests. If evidence contradicts this choice, add a superseding ADR with affected tasks; do not overwrite historical rationale. No executed validation is asserted by this record.
