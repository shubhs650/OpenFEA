# ADR-027: Explicit native connection review and bounded B08 gap experiment

Status: Accepted for bounded development; engineering-owner formulation/benchmark acceptance pending
Date: 2026-10-14

## Decision

T019 adds the actual workspace/API connection setup and review path. Suggestions never create assignments. Inspect immutable BREP in the existing read-only Bubblewrap/seccomp/no-network CAD sandbox under the unchanged 60 s / 1536 MiB / 192 MiB bounds and shared native lock. Native OCCT common-solid volume rejects intersections above 1e-12 m³. Opposing planar normals and common **trimmed projected faces**, rather than bounding boxes, establish candidate area/coverage/separation. Review is bounded to 100 faces, 1 mm positive separation search, 1e-10 opposing-normal dot tolerance, 1e-8 m² area equality and the existing 1e-8 m numerical coincidence. Unsupported surfaces produce no approvable pair.

Approval is deliberately restricted to complete opposing **unit-square** planar faces, including four distinct vertices with squared edge/diagonal lengths 1/2 m² within 1e-8 m². Partial interfaces and excessive gaps refuse. Physical separation above coincidence additionally requires `gap_approved` and an explicitly entered canonical metre tolerance covering the measured gap, capped at 1e-5 m. A separately declared 1e-12 m comparison allowance handles finite coordinate subtraction; this does not change B07 or numerical solver criteria. No auto-filled approval, healing, adjustment, bonding by proximity or tolerance extrapolation.

The server repeats native measurements before approval; the client cannot supply coverage or a substitute report. Recheck owner/tombstone/head before native inspection, after inspection and inside the write transaction. Persist original role/face/geometry UUIDs, SI gap decision, confirmed assumptions, measured pair, complete report, source/tool/isolation hashes and report SHA-256. Reports are private, transient scratch is removed and no uploaded deck execution is added. A face participates in at most one saved pair; ten pairs maximum. Unapproved suggestions are ephemeral.

Alembic `0008_bond_setups` adds append-only setup rows. Existing revisions read explicitly empty bonds; new revisions carry complete setup through materials/loads/units/name/mesh edits. Duplicate/conflict-copy/undo include bonds and never rewrite history or copy runs. Geometry repinning retains original assignments and marks geometry mismatch for explicit new review; it never transfers approval to new faces. Current mesh input snapshots capture saved bonds with an additive empty default for legacy snapshots. Physical mesh reuse excludes connection setup, since review does not alter connectivity.

## B08 declared model and measured scope

[B08 revision 1](../../tests/benchmarks/B08.json) freezes an ideal axial displacement-continuity model across a 10 µm empty gap between unit cubes, with independent 0.6/0.4 m C3D10 meshes. Gap adds **no** adhesive compliance: analytical ux is sigma/E times x in the left cube and x−g in the right, with free Poisson contraction. This is a kinematic assumption, not physical adhesive or contact modeling. No shear/bending-gap transfer claim follows.

The separate CLI experiment integrates the existing consistent mortar on a temporary projected coordinate view, then binds the equations back to the original physical mesh hash. Only the quadrature view closes the gap; emitted deck, source mesh, result geometry and native binary-coordinate audits retain it. Existing `prepare_bond`/`mortar_bond` zero-gap guards and B07 manifests remain unchanged. Both roles must meet every all-node displacement/all-IP tensor, external reaction/moment, tie residual, coverage/equation-count and binary-FRD coordinate criterion. Owner approval remains pending, and unsigned normal benchmark execution refuses before creating an output directory.
