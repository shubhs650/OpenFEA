# ADR-004: Minimal control plane and queue

Status: Proposed
Date: 2026-10-12

## Decision
Single API control host with SQLite WAL durable jobs and remote-worker protocol; one heavy job globally.

## Rationale
Five users do not justify a distributed microservice stack.

## Evidence/gate
Transactional reservation/claim, stale lease fencing and restore tests required.

## Alternatives not selected
Redis/Celery or Kubernetes by default; shared SQLite network file

## Consequences
Maintain the boundary in implementation and tests. If evidence contradicts this choice, add a superseding ADR with affected tasks; do not overwrite historical rationale. No executed validation is asserted by this record.
