# ADR-018: Revisioned face loads and immutable checked deck exports

Status: Accepted for T010 development
Date: 2026-10-13

## Decision

Store fixed, uniform-pressure and total-force assignments in append-only `analysis_load_setups` keyed by analysis/revision (migration `0004_loads_decks`). Assignments require the immutable geometry UUID and catalog face IDs. Deduplicate and sort selections, convert input pressure/force to SI once, retain original units/values, and derive body ownership from the pinned catalog. All analysis edits carry both material and load setups forward. Current-revision/owner/tombstone checks and the append/head update share one immediate transaction. Legacy load setups are explicitly empty; geometry replacement never transfers selections.

Pressure is positive inward and negative outward. New STEP imports record native OCCT planar outward normals and preserve original face orientation when tessellating copied shapes. Copied OCCT faces can lose owning-solid orientation; display triangles alone were insufficient. Pressure previews require agreement between the stored native normal and the verified display triangles. Legacy imports without that normal require reimport for pressure. Curved pressure is refused in this basic planar slice; curved fixed/force setup can be saved, but export remains planar.

One total global force is uniform traction over the complete deduplicated selected area. CAD area/centroid produce visible resultant/moment previews about the global origin; the mesh adapter uses existing tri6 quadrature and consistent quadratic nodal forces. Distinct overlapping loads require explicit combination confirmation. Signed loads add with a visible summary, including intentional cancellation; there is no silent cancellation, redistribution or remote rigid coupling. Fixed faces constrain global translations 1–3. Native CCX's CLOAD contract excludes constrained DOFs, so an integrated force component exceeding 1e-10 N on a fixed DOF refuses export. Smaller roundoff is retained, never dropped or reassigned.

T010 needs actual connectivity for a complete input deck. Use a bounded synchronous coarse mesh/export bridge before T011's durable asynchronous jobs: verified project-private BREP/body files, fixed per-body size = largest extent / 2, at most 100 planar faces and 3,000 elements. Reuse the existing Gmsh 4.15.2 affine C3D10 exporter, one-to-one area/centroid/bounds/adjacency mapping, midside and everywhere-positive-Jacobian checks. Disable OCC healing options. An unsuitable mesh refuses; no retries or automatic coarsening. Independent bodies each require a confirmed material and fixed face; this is not a general assembly stability proof.

Run Gmsh in filesystem/PID/network/user namespaces with readonly source/runtime/inputs, private writable scratch, dropped capabilities, inherited no-fork/namespace-escape/mount/ptrace filter and verified netdeny launcher. Share the import OS lock; a second native operation returns 429. Fixed limits: 60 seconds wall time, 1,536 MiB sampled process-tree RSS, 192 MiB scratch, plus existing hard launcher CPU/address-space/file limits. Namespace/dependency failures refuse; no unconfined fallback.

Freeze analysis, geometry, material and load setups in one read transaction before meshing. Export identity hashes the canonical frozen input plus fixed policy, native/runtime/lock and adapter hashes. Store immutable export records and project-scoped hash-verified deck, mesh and frozen-snapshot blobs. Recheck the current analysis and owner/tombstone under a write transaction after native completion before publishing. Cache hits verify all three artifacts; older downloads remain tied to their original snapshot after edits/restarts. List at most the latest 100 exports. There is no arbitrary uploaded-deck execution endpoint.

Deck output uses deterministic sorted nodes/elements/supports/loads/materials/surfaces and combined pressure entries. Material sets are split at CCX's 16-entry line limit. Validate per-assignment mesh area, force and moment against CAD before export, then check the actual decimal-written nodes/loads/combined pressures and their resultant/moment. Written connectivity also passes the affine/Jacobian checks. Fixed criteria: mapping area 1e-8 m² and coordinate 1e-6 m (existing); load area 1e-8 m², force 1e-8 N and moment 1e-8 N·m. Refuse overflow/underflow/nonfinite previews and export disagreement without relaxing criteria.

## Evidence and limits

[T010 evidence](../validation/T010.md) records native sign/reaction/stress references for six face orientations and both pressure signs, a two-body total-force case, byte identity through unit edits, a full independently authored reference deck, concurrency/migration/security/restart checks and real Chromium downloads. The bridge is a coarse preview, not a mesh-convergence, general CAD, assembly, signed benchmark or calculated product-result claim. Durable queue/cancellation/solve/run snapshots and results remain T011–T012. Laptop/Windows/GPU and owner engineering sign-offs remain deferred under the existing owner decision.
