# ADR-024 — Native geometry directions and planar symmetry

Status: Accepted for bounded development; engineering-owner acceptance pending
Date: 2026-10-14 (Asia/Calcutta)

T016 adds signed direction selection from an immutable native planar outward normal, straight edge's ordered endpoints or cylindrical axis. Native OCCT imports retain complete body-owned edge/vertex identities and face incidence, line endpoints and cylinder axis/point, bounded to 20,000 edges and vertices each. Edges select directions only; physical loads/supports target complete CAD faces. Requests cannot submit arbitrary bases. Resolve pinned references server-side, retain signed unit vector, right-handed orthonormal basis, origin and source geometry/reference in immutable setup/run snapshots; show sign, axes and arrows before saving. Legacy missing native edge/axis data requires reimport for that source. Curved symmetry refuses; cylinder-axis setup/preview does not authorize curved solving.

Preserve existing global force/displacement forms. Add signed scalar distributed force along the selected direction and directional displacement leaving other translations free. Planar symmetry is zero displacement along each selected face's own outward normal. Build one compatible constraint system per actual global node. Equal/reversed equivalent rows deduplicate; inconsistent values refuse, including shared edges/vertices and combined dependent rows. Do not overwrite node transforms, remove physical constraints, stabilize or redistribute loads.

Declare direction basis checks: finite vectors, length >1e-12 m for native straight edges, unit/basis orthogonality/right-handed error <=1e-10. A near-singular independent constraint residual between machine roundoff (64 double eps) and 1e-10 refuses rather than dropping a physical direction. Exact duplicate directions retain exact value conflict refusal; general dependent-row consistency permits only 64 ulps of the supplied displacement scale (no physical displacement floor). Necessary rank-six rigid-motion coverage uses the existing dimensionless 1e-10 policy on CAD topology vertices and actual mesh nodes, not general stiffness/assembly certification.

Pinned CCX 2.23 *TRANSFORM defines rectangular X'/Y' and assumes a right-handed frame; the last transform would overwrite an earlier one at the same node, so generate exactly one after all assignments are combined. Emit deterministic node sets, one common basis per node and local component boundaries (nonzero inside the step). Convert global CLOAD to that basis without dropping nodal forces. GRAV and element pressure remain global/native. Write transform basis components at 16 decimal exponent digits and independently parse the actual written frame/actions. Require *NODE PRINT,GLOBAL=YES and *NODE FILE,GLOBAL=YES for transformed nodes; local DAT/FRD cannot masquerade as global. Keep existing written force/moment audit, output coverage and resource/affine/planar guards.

External reactions are the orthogonal projection of global DAT RF minus written global applied CLOAD/pressure/gravity onto the node's external constrained span. Internal equation/tie/free components are excluded. Check written prescribed components using the unchanged 1e-12 m/1e-6 relative output criterion. Imposed nonzero orthonormal components contribute actuator magnitude reference; all T015 equilibrium thresholds/floors/origin and old raw artifact semantics remain unchanged. Freeze direction/constraint policy and source hashes; reconstruct frames from original written decks for owned immutable result views.

Before execution, B06 declares an exact ν=0.3 unit-cube uniaxial continuum patch: normal zero constraints on x=0/y=0/z=0, uniform total force +1000 N on x=1, other faces free. Compare unrotated and rigidly rotated/translated parts at two mesh sizes. Independent analytical displacement is [εx,-νεy,-νεz], ε=1000/E; transform vectors/tensors with the declared orthogonal rotation. All nodes and raw integration-point components are checked, no exclusions. U absolute 1e-13 m/relative1e-6; stress absolute0.01 Pa/relative1e-6; reaction force/moment0.001 N/N·m. Existing equilibrium policy applies. Rotation preserves displacement norms/von Mises and rotates full tensor and force/moment about the global origin; geometry remeshing does not imply node/IP identity. Owner sign-off stays PENDING and DEVELOPMENT never becomes formal acceptance.

Geometry cleanup conservatively invalidates all geometry-derived directions; preserve source scalar/SI values and old reference/basis, block export/solve, suppress stale arrows and require explicit face/direction review. Symmetry face reselection recomputes native normals. Undo restores captured original references only with the restored source geometry in a fresh revision; never overwrite later edits. Global assignments retain existing conservative face mapping. Density/material/unit edits, restart, old runs, ownership/ETag/CSRF/tombstone guards stay unchanged.

Required evidence: actual native B06 two meshes/both placements, nonzero local actuation, load/normal/edge reversal, cylindrical-axis native preview, curved symmetry and singular/conflicting basis refusal, shared-node deduplication, written global output/refusal, cleanup/review/undo, immutable units/restart and Chromium basis/sign/arrows/results. Preserve existing locks/binaries/benchmarks/owner/laptop deferrals. No new curved/assembly/convergence/capacity certification, deployment, AWS or billing. Next T017.

Initial encoding finding: identity B06 cases solved, but the first rotated deck was refused by pinned CCX because 16-decimal exponent fields exceed its 20-character numeric reads/card width. Correct the encoding to the existing 12-decimal exponent format (including subnormal exponents within 20 characters) before repeating in a fresh directory. Reconstruct frames from those exact written values and retain all original force/moment/output/reference criteria. No tolerance/physical setting changes; retain the original syntax failure.

Executed [T016 evidence](../validation/T016.md) records 492 distinct passing cases and all four real B06 runs. The encoding finding above corrects only decimal field formatting; initial criteria and syntax failure remain retained. Existing owner/laptop/M2–M4 deferrals stand.
