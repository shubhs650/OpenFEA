# ADR-020: Frozen core result views with element-owned contours

Status: Accepted for T012 development
Date: 2026-10-14 (Asia/Calcutta)

## Decision

Expose owned `GET /api/v1/runs/{job_id}/results` only for succeeded local solve jobs. Read the original immutable snapshot, generated deck, mesh, parsed output and native DAT/FRD through hash/size-verified private storage. Compare frozen input/deck/mesh/raw source identities and recheck ownership/tombstone after derivation. Mesh, queued, failed, cancelled and interrupted jobs cannot provide engineering results. Keep T011 raw artifacts and terminal records unchanged; views are deterministic derivatives with an explicit processor version and current processor source hashes, rather than silently rewriting completed runs. Historical views always use frozen material/yield/load values, including after edits/restart. No native execution or automatic retry occurs while viewing.

Retain the validated affine C3D10/raw DAT contract. Extrapolate the six tensors from four native integration points to each element's corners, interpolate tensors to midsides, then calculate von Mises. Do not extrapolate scalar von Mises, consume solver-averaged FRD for contours, or average shared element/body/material sides. Group raw samples by element to keep extrapolation linear in element count. Duplicate boundary vertices per element face and subdivide all tri6 faces into four triangles; render vertex colors over those display triangles. This is a derived boundary display, not a raw volume sample or a new curved-element formulation.

Displacement contours use native DAT nodal magnitudes. Report displacement extrema over every native node and stress/yield extrema over every raw integration point, including interior points, with location/entity/coordinates. Raw extrema can differ from extrapolated contour extrema. Contour clipping, hidden bodies, display units and deformation exaggeration do not change raw summaries. Three existing unit presets convert only at display boundaries; unapplied contour drafts clear on unit change, while applied ranges retain SI. Constant ranges within 1e-12 relative (1e-14 SI absolute floor) use uniform midpoint color and retain their actual numerical limits. Deformation is `x + scale*u`, explicit 0..1,000,000; default 0, physical scale 1. It never changes numerical arrays.

Per-body minimum ductile yield factor is frozen supplied yield divided by maximum raw integration-point von Mises. Missing yield is unavailable; stress ≤1e-6 Pa is unbounded/undefined with JSON null, never a fabricated finite safety value. Keep yield/singularity/linear-elastic caveats visible. Warn for yield exceeded and maximum displacement above 1% of that body's largest extent; the latter is a disclosed heuristic, not a validity certificate. No global safe-design badge or unrelated failure criterion.

CCX DAT RF is external force, including applied force. Read only the internally generated frozen deck's fixed/CLOAD/pressure records; compute equivalent written pressure loads on quadratic faces using written coordinates. External fixed-support reactions are RF minus those applied nodal contributions. Deduplicate fully fixed nodes and retain separate body totals, total force and moments about global origin. Do not call all RF values reactions, sum overlapping fixed selections twice, or count free-node/internal forces. Full force/moment equilibrium presentation and additional support/load types remain T015.

## Evidence and limits

[T012 evidence](../validation/T012.md) and [M1 exit review](../validation/M1-exit-review.md) record real axial/bracket/two-body solves, pressure touching fixed supports, zero/missing yield, output corruption, ownership/tombstone races, process restart and actual browser contours/units/history. The generated bracket is a public synthetic planar L prism, not private CAD. The declared development criteria and unchanged benchmark/owner dispositions are retained.

Scope remains the T011 100-face/3,000-element affine planar local pipeline. Components/principal fields, stress smoothing choices, probes, authoritative sections, refinement/convergence, general assemblies, target laptop/Edge/headed GPU, reports and owner-signed benchmarks remain their later tasks/gates. This completes the bounded M1 technical path, not the validated M4 product. No native/dependency lock, solver binary, frozen benchmark criterion, deployment or merge is changed.
