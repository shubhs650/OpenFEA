# ADR-034 — Bounded portable projects and private diagnostic previews

Status: Accepted for local T027
Date: 2026-10-15

## Decision

Archive v1 is a data-only ZIP with a strict manifest, project/setup/history JSON, tool identities and content-addressed objects. Export every supported geometry and analysis revision, including materials/source units, named load selections, mesh controls and bond reviews. Optional outputs include native meshes/raw results/logs and PDF/model/Word reports. Preserve original historical bytes and relationships as inert provenance; mark unselected and genuinely missing outputs explicitly. Corruption fails instead of becoming an omission. No authentication/session records, accounting credits, worker credentials or user-provided storage paths are serialized.

Import verifies schema, paths, hashes, sizes, references and CAD before one database publication. Assign new current-owner project/geometry/analysis/load/bond/history IDs. Original run/report bytes keep their original identities and are exposed only through owned attachment downloads in a separate imported-history table; they never enter the live job, report or mesh-reuse tables. Their provenance is untrusted, not numerical certification. Re-solving generates a fresh current-tool input/run through normal admission. Re-export retains inert history. Source publication failure rolls back metadata and removes newly staged blobs.

Validate canonical BREP in the existing offline/seccomp CAD namespace, with no repair or healing. Retain exact canonical BREP bytes/hash rather than reserializing them: OCCT read/write can change byte spelling and derived floating-point measurements. Regenerate native catalogs, body BREPs and display artifacts; ignore incoming derived metric/artifact claims. Require the same catalog identities, topology and ownership, then validate references against rebuilt catalogs. Recheck physical source/SI values and native directions. Rebind direction origins when vector and basis remain exactly equal; if either changes, retain the saved physical values and mark direction review required, blocking compute until explicit reselection. No approximate direction equality or new engineering tolerance is introduced. Remeasure saved bond reports natively and rebind their existing review checksums to new geometry UUIDs. Canonical source bytes, source units and applied SI values remain unchanged; regenerated previews are not promised byte-identical.

ZIP input/output ≤64 MiB; expansion ≤128 MiB; ≤512 entries; each entry ≤32 MiB; manifest ≤1 MiB; compression ratio ≤200. Generated ZIPs use stored entries, avoiding self-generated compression bombs. Reject absolute/traversal/drive/backslash/directory/nonregular/symlink/encrypted/duplicate/unsupported-method entries, undeclared or unreferenced payloads, recursive archives, unknown versions and migrations. Generated DOCX is an explicitly validated opaque historical report exception, never imported as executable content. No ZIP filesystem extraction. Bounded streamed uploads, one archive-upload slot, one bundle-build slot and the shared native-import lock prevent concurrent parser/build fan-out. CAD keeps its 60 s / 1.5 GiB sampled RSS /192 MiB scratch / no-network/seccomp limits; archive CAD validation has a 120 s aggregate deadline, at most eight geometry revisions. Export metadata queries use limit+one admission before serialization. Other v1 limits: 256 analysis revisions and 100 historical records; projects exceeding them refuse explicitly.

Diagnostic preview materializes an immutable bundle and displays exact included files, labels, sizes, hashes and omissions before its download link. Defaults contain only allowlisted latest-100 job kind/status/stage, selected options, tool hashes/versions and a raw-log omission notice. Names, IDs, coordinates, setup, raw log text, environment and reports are absent. Geometry and numeric raw/mesh results require separate explicit choices and warn about coordinates. Nothing is uploaded or sent to support. Raw solver input/logs remain available through existing owned fixed-name job downloads. All bundle/import/history lookups and downloads check current ownership/tombstones; writes require the existing local session and CSRF boundary.

## Verification and boundaries

Actual native archive round trips, fresh solve/equilibrium, multiple owners, failure rollback, expiry/corruption, catalog forgery, saved directions/bonds/cleanup ancestry, report/Word bytes and browser review/import/reload are tested. Focused malicious-ZIP tests cover paths, entry types, bombs, hashes, manifests and schema. See [T027 evidence](../validation/T027.md).

No archive executes a bundled deck/script, restores live queue state or accepts historical output as a successful current solve. No hosted identity, billing, deployment, restore scheduler or release-wide security acceptance is added. Preview bundles are retained locally; full quota/lifecycle and fault/capacity work remains T029/later retention tasks. Actual Windows/WSL2/laptop acceptance and later reference gates remain pending. Dependency locks, numerical tolerances, native limits and CI deadlines stay unchanged.
