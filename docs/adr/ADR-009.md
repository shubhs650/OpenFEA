# ADR-009: Local health bootstrap toolchain

Status: Accepted for T001
Date: 2026-10-12

## Decision

Pin Python 3.12.14, Node LTS 24.19.0, npm 11.9.0 and uv 0.12.23. Use a root uv development project (no build/package distribution yet), an npm workspace for React/Vite, and Make as the command interface. Commit the uv/npm locks and generated OpenAPI/TypeScript health contract. Install only the dependencies actually needed by the health slice; introduce SQLAlchemy, state libraries and native dependencies with their real implementations.

## Evidence and rationale

The existing cloud machine provides these runtimes. Python 3.12 ABI-compatible candidate OCP, Gmsh, VTK and NumPy wheels were downloaded from PyPI and checked against published hashes; see [wheel probe](../validation/wheel-probe.json). Choosing the available supported Python avoids an unnecessary runtime replacement. Wheel availability is not native compatibility or solver evidence. T002 must independently select and validate native versions and licenses. TypeScript 5.9.3 satisfies the locked typescript-eslint supported range; the current TypeScript 7 release exceeds it.

The current objective ends at the validated local prototype M4/T030. The supervisor launches actual loopback API/UI processes without Docker or privileged installation, checks behavior, and terminates only its own processes. No worker stub, solve route, fake result or cloud adapter is provided. Unsupported modes fail closed. Health is explicitly labeled bootstrap connectivity.

## Consequences

Setup uses immutable lock checks and repository-local caches. Runtime upgrades require an explicit pin/lock/report update and validation. The dependency report records exact artifacts, hashes, upstream metadata and licenses; it is not a project license or redistribution approval. Full native/benchmark/security/report gates fail explicitly until implemented. M0 numerical gates and final project license remain open. See [development commands](../DEVELOPMENT.md) and [validation evidence](../validation/T001.md).
