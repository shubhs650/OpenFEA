# Release gates

## Local validated prototype

- [ ] M0 experiments and dependency-license inventory complete; no unsupported solver claims.
- [ ] Actual STEP -> C3D10 -> CCX -> inspectable results -> report/archive workflow works.
- [ ] Bracket and nonconforming bonded support complete; benchmark manifests signed before runs.
- [ ] Required benchmark errors within frozen tolerances; invalid model and singular cases fail appropriately.
- [ ] Smoothed/unaveraged stress semantics verified; cap, failure, cancellation and retry tests pass locally.
- [ ] Chrome/Edge core flows and light/dark checked; no silent autosave or geometry-reference loss.
- [ ] PDF and DOCX rendered and checked, or explicit convenience-feature deferral recorded.
- [ ] Portable project archive round-trip and generated solver downloads verified.
- [ ] Known limitations and measured workload capacity documented; no fabricated performance claims.

## Invite beta

- [ ] ₹3,000 budget worksheet passes including fixed cost, taxes and reserve; actual pricing recorded.
- [ ] Deployment authorized; only India resources and non-interruptible worker configured.
- [ ] Google allowlist/session tests, all owner checks, archive/upload isolation pass.
- [ ] Independent worker TTL, reservation races, actual cancel, orphan recovery and credit accounting tested.
- [ ] Daily backup and restore drill completed; retention notices and deletion ledger verified.
- [ ] Rate card/allowances defined even though beta is owner funded; support diagnostic bundle works.
- [ ] Product owner reviews benchmark evidence and unresolved warnings; invite 3–5 users only after gate.
- [ ] Public redistribution license resolved if repository/container releases are public.

## Consider paid service later

- [ ] Reliability, usability and measured per-job cost targets met.
- [ ] At least three testers would pay the disclosed proposed rates.
- [ ] Separate payment/commercial operations scope approved; beta code is not labeled production-ready by default.
