# Geometry cleanup and assignment review

Import and confirm solid STEP, open its analysis if setup should follow the edit, and select one cylindrical feature face. **Preview feature removal** runs actual isolated OCCT defeaturing on a deep copy. The saved geometry and analysis remain unchanged until **Apply cleanup** is acknowledged.

Supported geometry is deliberately the two M0 unit-solid features: a 1 m cube with a radius 0.1 m through-hole on the z axis at (0.5,0.5), or its radius 0.1 m first straight-edge fillet. [Public synthetic fixtures](../tests/fixtures/geometry/) and [their generator](../services/worker/worker/geometry_native/edit_fixtures.py) reproduce them. Native solid differences verify the feature scope; a different radius, split topology, arbitrary cylinder, planar face or interacting feature refuses. General repair/healing and arbitrary imported defeaturing are unavailable. Failure retains the source.

**Show before cleanup** highlights affected original faces. **Show cleanup preview** shows the actual new tessellation and highlights changed faces. Review the before/after volumes, volume change and face mapping list, then confirm the geometry difference and assignment invalidation. Cancel discards the displayed preview without changing geometry/setup. Display detail remains a viewing choice.

Applying appends a geometry revision with its original parent, and, when an analysis was selected, appends that analysis's setup revision atomically. The one surviving body's confirmed material retains its SI properties and provenance. Loads/supports transfer only if every selected face has a unique, native-verified, unchanged full trimmed-face mapping. Removed, changed, split, merged or uncertain faces mark the entire assignment as needing review. Its original selections, magnitude, sign, direction and source quantities are retained; there are no partial force transfers, missing-face drops or guessed replacements. The blocker lists the exact face references. Unreviewed assignments have no load arrows/resultant contribution and prevent deck export, mesh and solve.

Select **all** intended replacement faces and choose **Reselect faces for …** on the affected assignment, or deliberately remove the assignment. Reselection retains its original SI/source load values, deduplicates faces and checks planar pressure and overlap requirements. Explicit overlap confirmation still applies. A new mesh is required after any geometry revision; old mesh jobs remain downloadable but cannot be used for a different geometry UUID.

**Undo applied cleanup** is a session command. It appends a revision using the original verified geometry artifacts and the captured analysis setup, rather than mutating geometry or completed runs. If another geometry/project or analysis edit has occurred since apply, undo refuses to overwrite it. Preview/apply/undo records and artifacts survive API restart; the browser's undo button is intentionally session-only. Reopen the project/analysis after a stale-revision error, then create a fresh preview.

Completed run history retains frozen geometry, material/load setup, mesh/deck and raw results. **View selected results** renders that run's geometry even if the current setup uses another geometry. It does not overlay current face assignments onto old results or reuse old meshes for new work. The original curved fixtures cannot currently be solved before cleanup: the existing planar affine mesh restriction remains explicit.

Limits are unchanged: one native operation, no network, a read-only source and private bounded scratch; 60 seconds, 1,536 MiB sampled RSS and 192 MiB output per CAD stage. This is bounded local development support, with no automatic healing, retry or certified arbitrary-geometry claim. [ADR-021](adr/ADR-021.md) defines mapping and concurrency rules; [executed evidence](validation/T013.md) records validation and remaining M3/M4 obligations.
