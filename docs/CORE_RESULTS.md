# Core local results

Generate a checked mesh, review the small-deformation elastic setup and solve it through [local jobs](LOCAL_JOBS.md). In **Engineering results**, choose a completed solve and open its results. The workspace's shared display switches from CAD/mesh to the run's actual calculated boundary. Close the result view or show CAD/mesh to return to face selection.

Select displacement magnitude, signed ux/uy/uz, six global stress components, von Mises or algebraically ordered principal stresses (σ1≥σ2≥σ3). Displacement comes from native DAT nodes; stress contours derive element-node tensors from native DAT integration points. The default keeps each element side separate, including quadratic midsides. The selected field table reports signed raw extrema, source node or element/IP, position and body/material side, with frame, canonical tensor order and units. Raw all-node/IP extrema include the interior and can differ from extrapolated surface peaks. Hidden bodies do not change the all-body range or extrema.

**Smooth stress within each body and material** optionally averages all incident volume element-node tensors equally at the same mesh node, then computes von Mises/principals. Body/material/node partitions never merge, even at identical coordinates, so discontinuities stay separate. Duplicate boundary faces contribute no additional weight. The derived view records each vertex's contribution count and method. This is display smoothing, not a convergence check; it can hide element jumps. Raw extrema, frozen yield factors, warnings and equilibrium never change with smoothing. Native FRD averaged stress remains diagnostic only.

Deformation scale 0 is undeformed, 1 is physical, and larger values exaggerate geometry only. Change the existing display-unit preset for mm–N–MPa, m–N–Pa or inch–lbf–psi. Force moments use the corresponding force × length units. Custom signed component/principal contour limits may be negative; magnitude/von Mises limits remain nonnegative. Limits clip colors only; reset restores the actual displayed surface/section sample range. Field or smoothing changes reset clipping. Constant fields use one color and equal numerical bounds. Unit changes clear unapplied contour drafts; already applied ranges keep their SI meaning.

Yield factor uses each body's **frozen** supplied yield and maximum raw integration-point von Mises under the ductile-yield assumption. Missing yield is unavailable. Essentially zero stress (≤1e-6 Pa) is unbounded/undefined rather than a large finite “safe” number. Yield exceedance, material warnings and support/reentrant-corner singularity caveats remain visible. The displacement/body-extent warning is only a heuristic; absence of warnings does not certify a design or small-deformation validity.

Reactions include each independent external constrained direction per node once, using global solver vectors. The processor subtracts the frozen generated deck's applied nodal/pressure/consistent-gravity contribution from native RF, including pressure that touches a support. It reports body totals and moments about global origin. T015 supplies frozen force/moment equilibrium and global component supports; T016 extends these to native geometry directions and planar symmetry. General refinement/convergence acceptance remains pending.

Run revision, geometry and artifact hashes identify the original solve. Editing materials, units or loads cannot change that run. Raw input/DAT/FRD/parsed downloads remain available from history. The owned result endpoint verifies retained sources and reports a versioned derived view with processor hashes; it refuses incomplete jobs or corrupt sources. Reopening the browser or restarting the API retains the same physical result. [ADR-020](adr/ADR-020.md) specifies this contract; [T012 evidence](validation/T012.md) records executed references and limits.

The current mesh is deliberately coarse and planar affine C3D10, capped at 3,000 elements/100 faces. The L bracket is workflow/equilibrium evidence; its stress peak is not a converged bracket allowable. General assembly validation, refinement, reports and target-laptop acceptance remain future gates. [ADR-029](adr/ADR-029.md) specifies T021 fields and smoothing; native benchmark/owner acceptance remains pending.

T015 extends these frozen results with [global component supports, consistent gravity subtraction and explicit force/moment equilibrium](ESSENTIAL_LOADS.md). Nonzero prescribed components contribute actuator forces; free-component/internal-tie RF never becomes an external support. Both certificates must pass before a solve publishes valid results. Near-zero scales use absolute checks and null normalized residuals. [Evidence](validation/T015.md) retains native references and rendered relative/absolute tables.

T016 extends external reactions to arbitrary supported directions by projecting global RF-minus-written-applied loads onto each node’s external constrained span. Both native nodal output cards explicitly use global coordinates when transforms exist; local outputs refuse. Node/DOF counts deduplicate dependent equivalent constraints, and nonzero reduced components retain actuator references. Original raw bytes and equilibrium criteria remain unchanged; processor derivatives identify the new source version. See [direction guide](GEOMETRY_DIRECTIONS.md) and [evidence](validation/T016.md).


For **Physical probes and volume sections**, enter undeformed physical x/y/z in the current length units. Download the retained volume mesh to find element IDs, then enter the explicit **Probe element ID**. At a shared boundary, probe each side separately; there is no automatic side selection or cross-boundary averaging. The result reports side IDs, physical position, barycentric coordinates, selected field and interpolation convention. Field/unit/smoothing changes update its displayed value from the same frozen tensors.

For a section, use the same physical position and a nonzero global normal and choose **Generate volume section**. The viewport shows actual retained-volume cuts, including sampled interior centroids; the normal magnitude has no effect. Outside/tangent planes have no area and show an empty section. Corners, edge midsides and centroids carry tensor/quadratic displacement values; the triangles between samples are a display approximation. Choose **Show exterior surface** to return. Both sides of coplanar material/body interfaces remain separate; use body visibility to inspect a side. Camera and field settings persist through these changes; **Reset result camera** fits the current visible geometry. State lasts within the open run, not across a browser reload or as a saved report view.

Probe/section samples are `element_interpolated`, not raw nodes/IPs. Unaveraged stress linearly interpolates each element's four-IP extrapolated corner tensors; smoothed stress quadratically interpolates its partitioned ten-node tensors. Invariants follow interpolation; displacement uses all ten C3D10 nodes. Raw extrema/yield/equilibrium/warnings retain their original meaning. Existing affine/planar guards refuse curved/non-midpoint volume results, even when curved mesh previews are available. Retained-data unavailability clears the open view and blocks new inspection; no cached surface substitute or automatic solve occurs. Scheduled retention remains T036. [ADR-030](adr/ADR-030.md) specifies this bounded contract.

For **Mesh refinement comparison**, duplicate the saved physical setup, explicitly change sizing, mesh and solve it. Open the reference run and expand the comparison panel. Choose a completed run in the same project, using **Refresh compared runs** after a pending solve finishes. Download both volume meshes for element IDs. Add up to eight labeled physical locations, retaining the same body side and reference coordinates with explicit element IDs in both meshes. Choosing a different run clears side bindings; changing fields retains physical points and invalidates the old comparison. Display-unit changes retain the saved SI positions.

**Compare physical samples** returns selected-field signed/absolute changes and a relative change divided by the absolute reference value. Near zero (≤1e-12 m or ≤1e-6 Pa), use the absolute change: the percentage is unavailable. These are display conventions, not accuracy thresholds. The separate raw peak table uses every native node/IP and keeps its original location; it may rise while fixed physical values are unchanged. Increasing peaks may indicate unresolved concentrations or singularities; no single comparison, lower smoothed peak or larger element count proves convergence or design safety. Different geometry, materials/provenance, loading, supports, bonds or solver contracts refuse rather than being presented as refinement.

Structured **Engineering assumptions and limitations** explain ductile yielding under the frozen supplied yield, the existing 1% displacement/extent heuristic and potential stress singularities. “No exceedance in this screen” never means a design is safe. Singularity is explicitly unassessed, not automatically detected; missing/essentially-zero yield assessment remains unavailable. Field/unit/range/exaggeration changes cannot remove these explanations. **Download comparison JSON with warnings** retains both frozen source identities, raw warnings, all explanations, exact physical samples, mode and denominator/interpolation conventions. It is an actual engineering-data export; PDF/Word and archives remain later tasks. Locations persist in the download; comparison drafts are session state. [ADR-031](adr/ADR-031.md) records the bounded contract.
