## Delivered path

Actual owned CSRF-protected POST `/runs/{id}/probes` accepts an element ID and physical undeformed point in metres. It inverts the affine volume map and refuses points outside that explicit side, with only 1e-12 barycentric roundoff admission. Boundary probes never silently choose or average adjacent sides. The response identifies physical position, element/body/material, barycentric coordinates, `element_interpolated` location, global frame, canonical six-component order, principal order, interpolation version/method and frozen source hashes. Interior samples have no native node/IP identity.

POST `/runs/{id}/sections` intersects each actual retained tetrahedral volume with the specified physical plane. It samples polygon corners, edge midsides and an independently evaluated interior centroid, then renders a fan of linear display triangles. This bounds output to nine samples/eight triangles per element, or 27,000/24,000 under the unchanged 3,000-element admission. It works without exterior boundary data in independent tests. Tangent/outside planes have no area. Both coplanar sides remain distinct; no coordinate/body/material merge occurs.

Displacement uses all ten quadratic C3D10 shape functions. Unaveraged tensors interpolate linearly from each element's four-IP extrapolated corner tensors; optional smoothed tensors interpolate quadratically from the exact body/material/node partition. Principal stresses and von Mises follow interpolation, never scalar averaging. The displayed triangles between samples are approximations. Neither interpolated peaks nor smoothing replace raw all-node/IP extrema or frozen yield/equilibrium/warnings.

Every request revalidates frozen input/mesh/deck/native DAT/FRD/parsed results and rechecks deletion before publication. No result read solves, retries, mutates terminal records or rewrites history. Missing/corrupt retained data refuses inspection, including after a successful prior section. Scheduled 30-day expiry/purge remains **T036**; T022 tests actual retained-source removal to simulate unavailable/expired data without claiming a scheduler.

The real workspace exposes unit-aware physical probe/plane inputs, a volume-mesh download for element IDs, both stress modes and all 14 fields on generated samples. Automatic section ranges use sampled volume values. Camera position, focal point, up vector, projection, scale and view angle persist through field/mode/section/unit/theme/visibility changes within the open run; reset fits geometry. This is session state, not a stored report view. Old responses cannot reopen a closed/switched run, and unavailable data clears the displayed result.
