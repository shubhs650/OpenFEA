## Executed behavior

Every numerical table cell/unit, warning, assumption and caption is compared with the same model. Editing/reopening both a paragraph and table cell succeeds without changing the original saved bytes. The exact archived T025 model and a 90-row Unicode layout stress fixture pass A4 bounds/repeated headers, final-row and image-width checks. Unicode Greek/accented/mathematical characters and conclusion attribution remain intact. Word's generated-version notice separates subsequent edits from numerical provenance.

The API exercises ownership/CSRF/strict request/lock contention, changed current setup, original PDF/model immutability, hash checks, database reopen, retained downloads after raw expiry, refusal of new generation from missing data, explicit renderer failure cleanup, source loss during publication, DOCX corruption refusal, SQL immutability and project tombstones. The browser generates Word for the selected PDF, verifies model/PDF hash identities and downloads it again after reload.

Final commands, counts, versions and artifacts are recorded after the final unchanged-source run. Intermediate issues receive no passing credit: the initial Word-history route collided with the existing generic report artifact route and was moved to `/reports/{id}/exports/word`; the isolated office converter required its `/bin` interpreter path; formatting/types and metadata length were corrected. A single mandatory report failure remains a failure until corrected; no numerical tolerance/deadline/retry was relaxed.

No solver, mesh, stress calculation or benchmark acceptance is changed. The root Python lock adds only python-docx 1.2.0/lxml 6.0.2; npm/native locks and binaries remain unchanged. Figures are embedded images with editable captions, not editable engineering meshes. Actual Word on Windows, target-laptop capacity/usability/Edge, archives/T027, later external-reference and release/security/redistribution acceptance remain NOT RUN/pending. No cloud deployment or merge is performed. The requested PR remains open while hosted CI is watched to success.
