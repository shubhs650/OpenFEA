## Reproduce and review

Use pinned native dependencies and `make benchmark CASE=B10 DEVELOPMENT=1 OUTPUT=/absolute/fresh-directory` (likewise B12/B13/B14). Each destination must be fresh. Failure retains the manifest, native files, logs and any completed mesh measurements; no automatic retry or overwrite. Network is denied for native mesh/solver children. Offline reference jobs have a fixed 10000-element export bound and existing 90-second process limit; product mesh/solve limits are unchanged.

All four new manifests use the existing exact-criteria approval gate: default execution refuses before output with pending, rejected or stale owner metadata. DEVELOPMENT always remains development evidence. The owner must review the exact criteria hashes, source interpretation, symmetry/formulation changes, B10 approximation and quantity selections before accepting them at the M4/T030 gate. The coding agent cannot supply that approval.
