## Failures investigated and corrected

Initial formatting and Python Literal typing errors were corrected and rerun. The initial httpx client emitted a Starlette deprecation; replacing it with supported pinned httpx2 removed that warning, with all 9 Python tests passing. The license-metadata fallback needed a concrete Path for mypy; this was corrected.

The first lifecycle run had 2 failures and 1 pass: TIME_WAIT caused restart preflight to fail, and the harness expected a `/proc/.../children` entry absent on this host. Preflight now uses the servers' SO_REUSEADDR policy while rejecting active listeners; the harness targets a supervisor-reported owned child PID. All 3 lifecycle cases passed after corrections. No assertion, tolerance or required gate was disabled. Final browser output includes only the runner's harmless color-variable warning.

A final cloud terminal interruption disconnected without delivering a foreground interrupt, leaving that verification session's services alive. They were explicitly stopped via their owned supervisor. A fourth integration case now verifies real SIGINT delivery to the Make foreground group releases the ports. Startup logs the supervisor PID, handles hangup, and cleans surviving child groups. [Development instructions](../DEVELOPMENT.md) document the explicit signal fallback for this cloud terminal behavior; all 4 integration cases passed. A closed tool session alone is not a shutdown check.
