## Corrections and limits

Development checks exposed two real native defects: copied display faces lost owning-solid orientation, reversing the pressure preview; and long per-material element-set lines exceeded CCX's 16-entry parser limit. Original native face orientation/normals and bounded material-set lines now fix both, with actual signed solves/regressions. Other development failures included missing type imports, library DTO field/selector mistakes and negative-zero display normalization. One full browser run was invalidated by editing API source while its hot-reload server was running; the unchanged-source final run passes. No timeout or numerical criterion was increased to conceal a failure.

Scope is the fixed bounded synchronous planar export bridge, before T011's durable mesh/solve queue, cancellation, run status and calculated results. Coarse independent bodies with fixed faces are not a general assembly stability proof. Curved pressure and curved/nonaffine deck export refuse; legacy geometry needs reimport for pressure normals. Full convergence/arbitrary-CAD, Windows/Edge, target laptop/headed GPU, signed exact benchmarks, gravity, bonds, reports, undo/duplication, global artifact retention/purge and M1/M4 acceptance remain future/unexecuted. Dependency/native locks, binary builds, frozen benchmark manifests and owner dispositions are unchanged.
