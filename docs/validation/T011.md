## Corrections and limits

Development checks caught import/type/selector issues, a reference-material edit that accidentally restored ν=0.3 instead of the declared ν=0, and a direct integration invocation that omitted the Makefile's worker PYTHONPATH. The old test asserting that solve routes do not exist was replaced with a guarded-submission test. CCX ignores an unknown keyword and can exit zero without a real solve; the validation correctly refused that output, and the deliberate nonzero solver-error fixture now uses the pinned parser's 16-entry line limit. No numerical tolerance or timeout was loosened.

Final review found and fixed a host resource-metadata write that could follow a native-created symlink, and a missing-artifact path that could block rather than terminally fail the worker. Executed threat/fault tests cover both. Interrupted raw diagnostic capture, full runtime/adapter fingerprints and immutable setup-warning propagation are recorded. No dependency/native lock, binary build, frozen benchmark criterion or owner disposition changed.

The final source commit includes that guard and the changed native cases, fast/build/smoke, integration and browser workflows were checked again with unchanged code. No numerical setting changed.
