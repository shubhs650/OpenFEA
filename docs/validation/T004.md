## Analytical/native observations

B09 is a conforming two-tetrahedron material patch with all six z=0 face nodes shared, not an independently meshed/tied assembly. E=210/70 GPa, nu=0.3 on both sides; prescribed continuous `u=(0.001x,-0.0003y,-0.0003z)` leaves shared node 2 ux free. Isotropic Hooke law gives 210/70 MPa axial stresses, zero other components and zero interface-normal traction. Same Poisson ratio permits the exact compatible displacement. Every raw IP and every derived element-node tensor is sampled; no singularity exclusions or smoothing are used.

- Native DAT: upper σxx=210,000,000 Pa, lower=70,000,000 Pa at all four IPs per element. Maximum raw/derived tensor error is **4.46e-7 Pa**.
- Native averaged FRD: **139,999,000 Pa** at all six shared nodes, within frozen 1e-4 relative tolerance of 140 MPa. Its approximately 1 kPa difference reflects CCX extrapolation coefficients/text precision; no adjustment was made.
- VTK: **2 quadratic tetrahedra, 14 global nodes, 20 element-owned points**, 8 raw IPs; each volume ≈1/6 m³. Tensor/position/ownership round-trips are exact in double precision. Metadata identify raw versus derived locations and source hashes.
- Hydrostatic fixture: σ=525 MPa I; von Mises≈0 and principal stresses≈525 MPa. Pure shear: τxy=32.3076923 MPa, von Mises=√3 τ and principals `(τ,0,-τ)`.
- Spatially varying case: harmonic, divergence-free quadratic `u_x=0.001yz`, so `σxy=mu·0.001z`, `σzx=mu·0.001y`, others zero. Native IP numbering/COORD, component permutation, element-corner/midside extrapolation and interior probe all match this independent reference.
