## Delivered behavior

FastAPI startup performs the real Alembic migration and creates/recovers one persistent local owner. SQLite WAL, foreign keys, FULL synchronous writes, explicit transactions and a busy timeout apply through SQLAlchemy Core. Project CRUD uses ETags, rejects stale writes, tombstones deletion and hides dependent metadata immediately. Every project/analysis/geometry read/write resolves ownership through a nondeleted owned project.

Immutable geometry metadata records retain source/BREP hashes, canonical metre declaration, confirmed source units, catalog, parent/edit recipe and validation provenance. Geometry registration is internal for a trusted CAD adapter; there is no browser endpoint that turns supplied hashes into validated CAD. Draft analyses optionally pin a same-project geometry record. Independent name edits append analysis revisions, and historic reads preserve earlier geometry/name/timestamps. Database triggers reject UPDATE/DELETE of geometry and analysis revisions.

The local session cookie is HttpOnly/SameSite=Strict with a process-lifetime random token. Mutations require the separate CSRF token. Peer/Host are loopback only; supplied browser Origin must match Host, and cross-site fetches are refused. The supervisor disables Uvicorn proxy headers and Vite preserves Host. Metadata bodies are bounded before JSON parsing, including false declared size, with an explicit Content-Length requirement. Beta/production startup rejects local bypass. Database errors are redacted JSON, not SQL/path responses. [ADR-015](../adr/ADR-015.md), [API contract](../API_CONTRACT.md) and [operator/API guide](../PERSISTENCE.md) describe the boundaries.

## Failures resolved during implementation

The initial direct invocation of the new process test omitted the API import path; its helper now uses explicit `--app-dir services/api`. The next run exposed a harness expectation that shutdown always returns zero: pinned Uvicorn logs completed shutdown and then propagates SIGTERM. The helper now requires completed shutdown plus exit 0 or SIGTERM, and the full real restart passes.

The first project browser flow failed 403: Vite's shorthand proxy sets `changeOrigin: true`, rewriting Host to the API port while preserving the browser's web-port Origin. The explicit proxy now sets `changeOrigin: false`; the original same-origin rule is preserved, and the same real browser case passes. A direct npm diagnostic also looked outside the configured browser cache; rerunning through the required Make target used the installed locked Chromium. No dependency/tolerance relaxation or skip was used to obtain a pass.
