## Real solve — expectations declared before execution

The generated fixture is one C3D10 tetrahedron in SI with E=210e9 Pa and nu=0.3. An affine displacement field imposes axial strain 0.001 and lateral strain -0.0003. Node 2's ux is free; all other DOFs are prescribed. Isotropic Hooke law predicts ux2=0.001 m and stress [210e6,0,0,0,0,0] Pa. The fixture/reference are committed in `tests/fixtures/native/`. Tolerances were frozen before the first solve: relative 1e-6, displacement absolute 1e-12 m, stress absolute 100 Pa, force balance absolute 10 N. None were widened.

## Diagnoses and corrections

- Network namespaces could not write uid_map. A no-new-privileges/seccomp socket-denial fallback was compiled and actual IPv4/IPv6 TCP/UDP creation denial exercised in all three environments. No proxy variables or inherited network descriptors enter native jobs.
- The first custom build passed ARCH as a string instead of the upstream Linux macro token; correcting the build override restored Fortran linkage declarations.
- GCC 14 rejects a legacy value return from a void function and defaults to non-common globals. Narrow `-Wno-error=return-mismatch` and `-fcommon` preserve older compiler conventions. `-fallow-argument-mismatch` supports the upstream Fortran calling style. No numerical source was changed.
- The relocated Fortran toolchain initially lacked its linker plugin/runtime development files. Exact signed Debian gcc/libgcc packages completed it; no trust checks were bypassed.
- OCCT diagnostics include an ANSI footer after application output. Explicit `OPENFEA_PROBE=` framing makes the one structured result unambiguous. Final native suite passes all cases.
- Final fixture review caught OCCT's default millimetre STEP units. The CAD probe now initializes its kernel/write units to metres, asserts the exported SI metre declaration and checks the restored 6 m³ volume. This availability check does not implement the application STEP-unit confirmation workflow.

Only documented SPOOLES draw filename and official I2Ohash corrections were applied to extracted third-party copies. Source archives/locks remained unchanged. No tolerance/assertion was disabled and no fake solver result was introduced.
