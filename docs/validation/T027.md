## Executed scope

The public API exports versioned ZIP manifests, all supported geometry/analysis revisions and optional raw/report outputs, imports under new current-owner identities atomically, and retains original history as inert owned attachments. Fresh meshing/solving follows ordinary current-tool admission. Archived solver input is never executed. Exact canonical BREP is retained; native body artifacts, topology, metrics and previews are rebuilt in the bounded offline CAD namespace. Saved directions retain physical vectors/bases or explicitly require review; native bond measurements/checksums and geometry ancestry are revalidated/rebound. Imported original PDF/model/Word bytes, warnings and view definitions remain unchanged.

Default diagnostic ZIPs contain anonymous job kind/status/stage, tool hashes, explicit choices and raw-log omission notice. Their downloaded bytes exclude project/run/geometry/body identities, names, filenames, coordinates, setup, raw logs and reports. Separate geometry/result choices reveal exact included files/purposes/sizes/hashes before download. No upload to support occurs. Existing original-run fixed-name input/log downloads remain available.
