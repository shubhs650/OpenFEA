# T027 — Portable archives and diagnostic bundle evidence

Date: 2026-10-15 (Asia/Calcutta)
Status: implementation verification in progress.

[ADR-034](../adr/ADR-034.md) and the [export guide](../REPORTS_EXPORTS.md) define the implemented format, safety limits, native revalidation and browser path. Evidence uses synthetic/public repository fixtures only. Original T024 engineering approvals and all numerical tolerances remain unchanged. No dependency lock, solver binary, automatic retry or CI deadline is changed.

## Executed scope

The public API exports versioned ZIP manifests, all supported geometry/analysis revisions and optional raw/report outputs, imports under new current-owner identities atomically, and retains original history as inert owned attachments. Fresh meshing/solving follows ordinary current-tool admission. Archived solver input is never executed. Exact canonical BREP is retained; native body artifacts, topology, metrics and previews are rebuilt in the bounded offline CAD namespace. Saved directions retain physical vectors/bases or explicitly require review; native bond measurements/checksums and geometry ancestry are revalidated/rebound. Imported original PDF/model/Word bytes, warnings and view definitions remain unchanged.

Default diagnostic ZIPs contain anonymous job kind/status/stage, tool hashes, explicit choices and raw-log omission notice. Their downloaded bytes exclude project/run/geometry/body identities, names, filenames, coordinates, setup, raw logs and reports. Separate geometry/result choices reveal exact included files/purposes/sizes/hashes before download. No upload to support occurs. Existing original-run fixed-name input/log downloads remain available.

## Verification record

Final command counts, implementation commit/tool identities and retained artifact hashes are recorded in the evidence index after execution. Hosted CI is monitored on the requested PR; its exact final head/result is linked there without pre-crediting unexecuted checks.

Intermediate failures receive no passing credit: frozen-model field replacement was corrected; the historical allowlist now includes the actual `solver.log` name; native BREP reserialization drift led to exact canonical-byte retention plus rebuilt trusted derivatives, rather than numerical tolerance changes; native direction origins and geometry-bound bond checksums are explicitly rebound. The browser waits for actual solve completion before export (active runs intentionally refuse). Earlier failing runs are superseded only after their final replay passes.

Not run: actual Windows/WSL2 laptop/Word/Edge/headed GPU/capacity/usability; remaining tutorial/external references; release-wide/hosted auth/security/billing and lifecycle/quota acceptance. Archives are bounded local data portability, not a trusted engineering signature or arbitrary legacy-format migration. Imported history cannot be reused as a live successful run/mesh. Direction vector/basis drift requires explicit review, not silently altered loads. Full security acceptance remains blocked; focused archive attack tests are not that gate. No cloud deployment or merge is performed. Next task is T028 after review.
