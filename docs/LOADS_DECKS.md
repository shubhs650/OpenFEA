# Face loads and checked deck export

Create/open an analysis pinned to accepted STEP geometry and assign a confirmed material to each body. Select faces in the viewport or body tree. In **Fixed faces and loads**, give an assignment a name, choose Fixed, Uniform pressure or Total distributed force, and save. The selection is copied into the new immutable analysis revision; changing the current selection does not edit an existing assignment. Remove an assignment and save a replacement to change it. Stale edits refuse; use **Reload saved analysis (discard edits)** before applying again.

- Fixed constrains all three global translations on every selected face, including C3D10 midside nodes.
- Pressure uses the current stress units. Positive pressure acts inward, negative pressure outward. Planar native normals are verified against display orientation. Imports made before T010 need reimport for pressure; old analysis geometry remains pinned.
- Total force uses the current force units and global X/Y/Z components. The entered vector is spread once over the entire deduplicated selected area, in proportion to area. This is uniform traction, not remote rigid coupling. Zero vectors, point loads and remote moments are unsupported.

Saved assignments show arrows/fixed glyphs, their signed combined resultant in N and moment in N·m about the global origin. Positive pressure arrows end at the face; outward pressure and total-force arrows start at the face. Glyph lengths are illustrative. Hiding a body hides its glyphs; camera and coarse/fine display changes do not alter saved physics. Overlapping pressure/force assignments need the visible explicit combination checkbox. Confirmed signed loads add, including intentional cancellation. Changing display units copies saved SI/source quantities exactly and clears unsaved load numbers so a draft cannot acquire a different physical meaning.

**Generate checked deck** freezes the current analysis and builds actual Gmsh C3D10 connectivity in a bounded isolated process. Each independent body requires material and a fixed face; add at least one nonzero load. Export currently requires at most 100 planar faces, 3,000 affine quadratic tetrahedra and a fixed coarse per-body mesh size (largest extent / 2). It can refuse an ambiguous mapping, thin/degenerate mesh, resource limit, missing namespace/dependency or mismatch between CAD and exported load resultants/moments. Curved fixed/force setup can be saved for later work, but cannot yet export. There is no automatic healing, stabilizing, bonding, retry or coarsening.

Distributed force that reaches fixed degrees of freedom is rejected when an integrated component exceeds the declared 1e-10 N roundoff threshold. Choose separated support/load faces; the exporter does not discard or redistribute force. Pressure uses CCX's native positive-inward `*DLOAD`. Explicitly combined pressure entries add on each element face. Materials are canonical isotropic `*ELASTIC`; density/yield metadata remain in the snapshot, with gravity/failure calculations deferred.

Successful exports appear under **Saved deck exports** with the original revision, element count, SHA-256, **Download analysis.inp** and **Download frozen snapshot**. Downloads remain identical after later setup edits and application restarts. Repeating export for the same snapshot/tool policy uses verified cached artifacts; unit-only revisions regenerate the same numeric deck bytes. The snapshot includes pinned analysis/geometry/material/load inputs and native/tool/source hashes. It is an export snapshot; T011 will add durable solve/run snapshots and status.

The deck contains actual nodes, C3D10 elements, per-body material sets, CAD face surfaces, fixed boundaries and calculated `*CLOAD`/`*DLOAD`, followed by a static step and raw output requests. This coarse preview does not establish convergence or a successful product solve. Solving, calculated fields and reports remain later tasks. See [ADR-018](adr/ADR-018.md) and [executed validation](validation/T010.md).
